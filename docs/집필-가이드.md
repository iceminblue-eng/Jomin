# 집필 가이드 — 강의안(PPT) → 단행본 원고 변환 규칙

『관리자론 — 헤어살롱 편』의 모든 장은 이 규칙에 따라 집필한다.
1장(샘플)에서 확정된 기준이며, 이후 장은 이 문서를 준수한다.

---

## 1. 이 책의 성격

| 항목 | 정의 |
| --- | --- |
| **제목** | 관리자론 — 헤어살롱 편 |
| **성격** | 미용 시장 **관리자 운용 바이블** (읽는 책 + 찾아보는 책) |
| **1차 독자** | 중대형 살롱 원장(40평 이상 · 8인 이상), 다점포 원장(2개 지점 이상) |
| **2차 독자** | 총괄 관리자를 지향하는 일반 관리자 · 실장급 |
| **원본** | 강의용 발표 PPT(장당 15슬라이드 내외) |

**핵심 원칙:** 강의를 들은 사람은 되짚어 볼 수 있어야 하고, 강의를 듣지 않은 사람도 혼자 완결할 수 있어야 한다.

## 2. 슬라이드 → 원고 변환 규칙

### 2-1. 절대 원칙

| 규칙 | 내용 |
| --- | --- |
| **골격 보존** | 슬라이드의 상수·변수·결정 규칙·판정 기준·수치는 **변경하지 않는다.** |
| **살 붙이기** | 슬라이드의 단문 불릿은 반드시 **왜 그런가 + 현장에서 어떻게 나타나는가**로 확장한다. |
| **불릿 금지** | 슬라이드를 불릿째로 옮기지 않는다. 개념은 산문으로, 도구는 표로 바꾼다. |
| **자립성** | 강의 없이도 읽히도록, 슬라이드에 없던 정의·배경·오해 해소를 보충한다. |
| **출처 구분** | 슬라이드에 없는 수치·통계는 쓰지 않는다. 저자 경험칙은 **"현장 경험칙"으로 명시**한다. |

### 2-2. 슬라이드 유형별 처리

| 슬라이드 | 원고에서의 처리 |
| --- | --- |
| 표지 | 장 제목 + 적용 범위 + **「이 장의 좌표」 표** |
| OPENING QUESTION | 「여는 질문」 — **현장 장면(대사)으로 시작**한 뒤 셀프 체크를 빈칸 양식으로 제공 |
| 학습 목표 · 매트릭스 대입 포인트 | 「이 장이 끝나면 할 수 있어야 하는 것」 + 매트릭스 개념 재설명 |
| 도입 · 임계점 | 신호 목록을 **각 1문단으로 확장** + 개수 판정표 추가 |
| 핵심 개념 | 비교표 유지 + **가장 중요한 행을 지목** + 「오해 해소」 절 추가 |
| 병목의 해부 | 병목별로 *현장 전개 시나리오* + *처리 방향 예고* |
| 진단 실험 | **측정 방법 · 기록 양식 · 결과 해석 구간**을 새로 붙인다 |
| STEP 1 상수 | 상수마다 *왜 상수인가* + ***이 상수가 깨질 때 나타나는 현상*** |
| STEP 2 변수 | 질문표 유지 + 판정 구간표 + 「이 문항의 진짜 용도」 |
| STEP 3 결정 규칙 | 플로우 유지 + **용어 정의**(예: '핵심 업무'의 분모) + 순서 불가역 이유 |
| STEP 4 현장 사례 | 서사로 재구성: 상황 → 전개(번호) → 매트릭스 재해석 → **실제 비용** → 교훈 |
| STEP 5 실행 도구 | 체크리스트에 **「통과 기준」 열 신설** (판정 가능하게) |
| WORKSHOP | **조별 수업 버전 + 혼자 읽는 독자 버전** 두 갈래 |
| SUMMARY / NEXT | 「장을 닫으며」 3줄 + 다음 장 예고 |
| HOMEWORK | 「과제」 + **왜 이 과제가 다음 장의 재료인지** 명시 |
| — | **「요약 카드」 신설** (슬라이드에 없음 · 바이블 성격상 필수) |

## 3. 문체 규정

| 항목 | 규정 |
| --- | --- |
| **본문** | **합니다체.** 강의에서 온 책이므로 원장에게 말 거는 어조를 유지한다. |
| **상수·원칙 문장** | **한다체.** ("순서는 바뀌지 않는다", "기록 없는 예외는 원칙 붕괴의 시작이다") |
| **지시문·과제** | "~하십시오." ("~하세요"보다 문어에 적합) |
| **호칭** | 독자는 '원장님'이 아니라 **'원장'** 또는 2인칭 생략. 과잉 존대 금지. |
| **인용 블록** | 상수, 핵심 정의, 판정 플로우, 3줄 요약에만 사용 |
| **강조** | **굵게**는 문단당 1~2회. 남용하면 강조가 소멸한다. |
| **외래어** | 현장 용어는 그대로(카운셀링·클레임·시재·워크인·인턴). 경영학 용어는 우리말 우선. |
| **위트** | **필수.** 구역과 기법은 3.5절 참조. 위트 없는 원고는 반려한다. |
| **은유** | **고정 은유 사전(3.6)을 따른다.** 장마다 새 비유를 만들지 않는다. |

### 금지 표현
- "~인 것 같습니다", "~라고 볼 수 있습니다" 등 판단 회피 → **단정하거나 조건을 명시한다.**
- 근거 없는 통계 수치 ("업계의 73%가…")
- 특정 브랜드·실명 매장 언급
- 강의 현장 지시어 ("이 슬라이드에서 보시면", "옆 사람과 이야기해 보세요")

## 3.5 위트 규정 — 어디서 웃기고, 어디서 절대 웃기지 않는가

독자는 미용인이다. 딱딱한 경영서는 **끝까지 안 읽힌다.** 위트는 장식이 아니라 **완독률을 만드는 장치**다.
단, 아무 데나 넣으면 경영서의 무게가 무너진다. 아래 구역을 지킨다.

### 위트의 원칙 — '농담'이 아니라 '공감'

목표는 "재밌다"가 아니라 **"아 맞아, 우리도 저래"**다.
독자가 웃는 지점은 문장이 아니라 **자기 매장이어야 한다.**

### 웃음의 대상 (반드시 지킬 것)

| 대상 | 가능 여부 |
| --- | --- |
| **상황·구조** | ✅ 주 타깃. "말했다 vs 못 들었다는 업계 최장수 논쟁입니다. 우승자는 아직 없습니다." |
| **원장 자신 (독자)** | ✅ 단, 애정을 담아. "화장실에서 카톡으로 승인하셨다면 그건 휴무가 아닙니다." |
| **저자 자신** | ✅ 권장. 저자가 먼저 웃음의 대상이 되어야 원장을 놀릴 자격이 생긴다 |
| **직원·팀원·신입** | ❌ **금지.** 독자가 원장이므로, 직원을 웃음거리로 삼으면 책이 편이 갈린다 |
| **고객** | ❌ **금지.** 서비스업 종사자가 고객을 비웃는 책은 팔리지 않는다 |
| **특정 매장·실명** | ❌ 금지 |

### 위트 금지 구역 (건조하게 쓴다)

| 구역 | 이유 |
| --- | --- |
| **상수 문장 (한다체)** | 웃기면 권위가 죽는다. 원고에 "여기서부터는 농담을 줄이겠습니다"로 명시적 전환 |
| **판정 기준 · 수치 · 구간표** | 도구는 도구답게. 채점표에서 농담하면 아무도 채점하지 않는다 |
| **체크리스트 항목 본문** | 통과 기준은 건조하게. 단, 표 밖 리드 문장에는 가능 |
| **사례의 결말 (퇴사·실패)** | 사람이 나간 이야기다. 여기서 농담하면 잔인해진다. 상황 설명까지만 위트 허용 |
| **다음 장 예고** | 예고는 약속이므로 정직하게 |

### 위트를 만드는 다섯 가지 기법

**1. 미용 언어로 번역한다 (최우선 · 이 책의 주무기)**
원장은 이미 진단·레시피·시술 이력의 사고를 한다. 경영 개념을 그 언어로 옮기면 **위트와 이해가 동시에** 온다.

| 경영 개념 | 미용 번역 |
| --- | --- |
| 상수 × 변수 | 염모제 레시피 × 모발 상태 |
| 진단 없는 실행 | 모발 진단 없이 약 올리기 |
| 원인 오분류 | 베이스 안 뺐는데 약제 탓하기 |
| 예외 미기록 | 시술 이력은 남기면서 승인 이력은 안 남기기 |
| 부재 테스트 | 매장 손상도 테스트 |

> **핵심 문장** — "우리는 고객 모발은 그렇게 꼼꼼히 진단하면서, 정작 매장은 한 번도 진단하지 않습니다."

**2. 현상에 이름을 붙인다**
이름이 붙으면 웃기면서 동시에 기억된다. 예: `눈치 커리큘럼` · `전설의 그때 그 서비스` · `'원장님' 호출 지수` · `A파 B파 눈치파`

**3. 문단 끝 한 줄 착지**
설명 문단을 짧은 반전 한 줄로 닫는다.
> "조회는 분명히 했습니다. 다만 그 조회는 9시에 끝난 게 아니라 **9시 3분에 증발**했습니다."

**4. 대사로 재현한다**
미용실 대화는 그 자체로 리듬이 있다. 설명하지 말고 들려준다.
> "원장님, 이거 서비스로 해드려도 돼요?"

**5. 선제적 방어**
독자가 속으로 할 반박을 저자가 먼저 말한다.
> "이 말씀을 드리면 대개 표정이 굳으시는데, 바로 그 표정이 이미 1차 진단 결과입니다."

### 밀도 기준

- **개념·도입·병목·사례 상황부** — 소절당 위트 1~2회
- **STEP 1 상수 / 판정표 / 체크리스트** — 0회
- **닫으며·과제** — 마지막 한 줄만 가볍게

**과유불급.** 한 페이지에 세 번 이상 웃기려 들면 개그책이 되고, 원장은 이 책을 직원에게 못 준다.

### 절대 쓰지 않는 것

- `ㅋㅋ` · 이모지 · 유행어 (책의 수명이 2년으로 줄어든다)
- 자학 개그로 위장한 진짜 자기비하 ("뭐 제가 뭘 알겠습니까만")
- 냉소 ("어차피 안 바뀝니다")
- 남의 매장 비웃기

## 3.6 은유 체계 — 책 전체를 하나의 비유로 묶는다

1장에서 채택한 미용 비유를 **끝까지 확장한다.** 장마다 새 비유를 찾지 않는다.

### 원칙 문장

> **미용사가 고객에게 하는 일을, 원장은 매장에게 한다.**

이 한 문장이 책 전체의 은유 축이다. 독자는 이미 이 사고를 매일 하고 있으므로,
경영 개념을 여기에 얹으면 **설명이 짧아지고 위트가 동시에 생긴다.**

### 고정 은유 사전 (전 장 공통 · 변경 금지)

한 개념은 끝까지 같은 비유로 쓴다. 1장에서 상수가 '레시피'였으면 13장에서도 레시피다.

| 경영 개념 | 고정 은유 | 최초 등장 |
| --- | --- | --- |
| 상수 | **염모제 레시피 / 시술 프로토콜** | 1장 |
| 변수 | **모발 상태 · 두피 상태** | 1장 |
| 구조 진단 | **모발 진단** | 1장 |
| 진단 없는 실행 | **진단 없이 약 올리기** | 1장 |
| 원인 오분류 | **베이스 안 뺐는데 약제 탓하기** | 1장 |
| 기록 | **시술 이력 카드** | 1장 |
| 기록 없는 예외 | **애드리브 배합** | 1장 |
| 구조 붕괴 | **손상** | 1장 |
| 사람별 편차 | **디자이너마다 다른 마무리** | 1장 |
| 표준 커리큘럼 | **아카데미 커리큘럼** | 1장 |

| 역할 경계 | **시술 단계별 담당 구분** | 2장 |
| 이중 지시 | **인턴이 두 디자이너 어시를 동시에** | 2장 |
| 권한 없는 책임 | **도포는 시키고 배합은 못 보게 하기** | 2장 |
| 평가 항목 | **무엇을 재느냐** (샴푸 속도만 재면 두피를 안 본다) | 3장 |
| 승진 | **평가표의 교체** (승급시켰는데 어시 평가표로 평가) | 3장 |
| 굵은 상수 | **배합 원리 10개** (vs 레시피북 500개) | 4장 |
| 준상수 재측정 | **모발 상태는 6개월이면 바뀐다** | 4장 |
| 규정 다이어트 | **약장 정리** (같은 약 세 병 · 유통기한 지난 것) | 4장 |
| 좌표에 대한 정답 | **좋은 약은 없다, 이 모발에 맞는 약이 있을 뿐** | 5장 |
| 좌표 오독 | **선 트리트먼트 없이 탈색 올리기** | 5장 |
| 다점포 | **같은 색을 다른 손으로 재현하기** | 5장 |
| 실질 부하 | **예약 건수가 아니라 시술 시간으로 세기** | 6장 |
| 사각지대 | **자기 뒤통수는 자기가 못 본다** | 7장 |
| 보완형 관리자 | **거울을 하나 더 놓는 것** | 7장 |
| 위임 단계 | **인턴→주니어→디자이너 승급 단계** | 7장 |
| 운영 코드 | **시술 차트 한 줄** (레벨7·손상3·기염색2회·두피민감) | 8장 |
| 관리 시간 확보 | **교육 시간을 예약표에 먼저 넣기** | 9장 |
| 오피스형의 영역 | **재료상 사장님** (시술은 안 하지만 약제는 더 안다) | 10장 |
| 첫 90일 | **선 트리트먼트** | 10장 |
| 복수형 분담 | **두 손은 경쟁하지 않는다** (가위 든 손 · 판넬 잡는 손) | 11장 |
| 90일 시험운영 | **스트랜드 테스트** (전체 올리기 전 한 가닥 먼저) | 12장 |
| 인건비 vs 운영 손실 | **싼 약제 값만 세고 재시술 비용은 안 세기** | 12장 |
| 승인 한도 | **"적당히 발라"는 레시피가 아니다** | 13장 |
| 실패할 권리 | **인턴이 처음 약을 발라 볼 기회** | 13장 |
| 예측 가능성 | **"지난번과 같은 색이 나온다"** (재방문의 이유) | 14장 |
| 개인 보관 정보 | **개인 수첩에 있는 시술 이력** | 15장 |
| 구조 언어 변환 | **"머리가 이상해요" → "언더톤 미제거"** | 16장 |

새 개념에 은유를 붙일 때는 **이 표에 먼저 추가하고** 쓴다. 표에 없는 즉흥 비유는 쓰지 않는다.

### 장별 확장 계획

| 장 | 주제 | 확장할 미용 대응 |
| --- | --- | --- |
| **1장** | 구조 진단 | 모발 진단 — 레시피(상수) × 모발 상태(변수) |
| **2장** | 역할 경계 | ✅ **시술 단계별 담당 구분** — 시술 한 건에 손이 몇 개 들어가는가 |
| **3장** | 관리자 평가 | ✅ **재는 것이 행동을 만든다** — 샴푸 속도만 재면 두피를 안 본다 |
| **4장** | 3층 문법 | ✅ **배합 원리 10개 vs 레시피북 500개** + 약장 정리 |
| **5장** | 구조 좌표 | ✅ **좋은 약은 없다, 이 모발에 맞는 약이 있을 뿐** |
| **6장** | 조직 좌표 | ✅ **예약 건수가 아니라 시술 시간으로 세기** |
| **7장** | 사람 좌표 | ✅ **자기 뒤통수는 자기가 못 본다** |
| **8장** | 운영 코드 | ✅ **시술 차트 한 줄로 인수인계하기** |
| **9장** | 선수형 | ✅ **교육 시간을 예약표에 먼저 넣기** |
| **10장** | 오피스형 | ✅ **재료상 사장님** + 첫 90일은 선 트리트먼트 |
| **11장** | 복수·혼합형 | ✅ **두 손은 경쟁하지 않는다** |
| **12장** | 유형 결정 | ✅ **스트랜드 테스트** |
| **13장** | 권한 위임 | ✅ **"적당히 발라"는 레시피가 아니다** |
| **14장** | 팀원 신뢰 | ✅ **"지난번과 같은 색이 나온다"** |
| **15장** | 이원 리더십 | ✅ 개인 수첩 vs 공용 차트 |
| **16장** | 갈등 조정 | ✅ **클레임을 차트 언어로 바꾸듯** |
| **17장~** | 실무 운영 | 강의안 확인 후 조정 |
| **9~12장** | 관리자 유형 | **약제 선택** — 같은 목표라도 모발 상태에 따라 다른 약을 쓴다. 관리자도 매장 상태에 따라 유형이 갈린다 |
| **13장** | 권한 위임 | **어디까지 스태프에게 맡기는가** — 배합까지? 도포까지? 체크까지? |

*✅ = 집필 완료. 17장 이후는 강의안 확인 후 조정하되, 고정 은유 사전은 그대로 유지한다.*

### 남용 방지 규칙

| 규칙 | 내용 |
| --- | --- |
| **장당 핵심 은유 1개** | 서브 은유는 최대 2개. 그 이상은 비유가 내용을 밀어낸다 |
| **은유 다음엔 반드시 번역** | 비유로 끝내지 않는다. 바로 다음 문장에서 실무 언어로 옮긴다 |
| **안 맞으면 안 쓴다** | 억지로 끼워 맞춘 비유는 최악이다. 그 장은 은유 없이 간다 |
| **출처는 미용 기술로 한정** | 스포츠·군대·전쟁·스타트업 비유 금지. 이 책의 차별점이 사라진다 |
| **상수 문장에는 은유 금지** | 상수는 비유가 아니라 원칙이다. 그대로 지킬 문장이어야 한다 |

### 나쁜 확장 vs 좋은 확장

| 나쁜 확장 | 왜 나쁜가 | 좋은 확장 |
| --- | --- | --- |
| "관리자는 매장의 헤어 디자이너입니다" | 대응이 헐겁다. 아무 말이나 붙일 수 있다 | "약을 누가 배합하고 누가 바르는지 정해져 있듯, 결정도 누가 어디까지인지 정해져야 합니다" |
| "매출은 매장의 모발 볼륨입니다" | 억지. 독자가 먼저 알아챈다 | (은유 없이 그냥 매출로 쓴다) |

## 4. 장 표준 구조 (13절)

```
1. 장 제목 + 적용 범위 + 「이 장의 좌표」 표
2. 여는 질문 (현장 장면 → 셀프 체크 양식)
3. 이 장이 끝나면 할 수 있어야 하는 것 (+ 매트릭스 대입)
4. 임계점 / 문제 정의
5. 핵심 개념 (비교표 + 오해 해소)
6. 병목 또는 구조 해부
7. 진단 실험 (측정 · 기록 양식 · 해석 구간)
8. STEP 1 · 상수
9. STEP 2 · 변수
10. STEP 3 · 결정 규칙
11. STEP 4 · 현장 사례
12. STEP 5 · 실행 도구 (체크리스트 + 판정)
13. 워크숍 → 장을 닫으며 → 다음 장 예고 → 과제 → 요약 카드
```

**분량 기준:** 장당 원고 30,000~40,000자(공백 포함). 1장 실측 35,027자.

## 5. 일관성 유지 장치

| 장치 | 규칙 |
| --- | --- |
| **매트릭스 대입 포인트** | 모든 장은 상수 × 변수 프레임 안에서 자기 위치를 명시한다 |
| **장 간 참조** | 미룬 주제는 반드시 장 번호로 예고한다 (예: "3장에서 상세히 다룹니다") |
| **판정 3구간** | 모든 진단 도구는 **3구간 판정**(가능 / 병행 / 보류)으로 통일한다 |
| **다점포 주석** | 다점포에 다르게 적용되는 지점은 `📌 다점포 원장을 위한 주석` 박스로 처리 |
| **산출물 연결** | 각 장의 과제 산출물은 다음 장의 입력 재료가 되도록 설계한다 |

## 6. 원고 검수 체크리스트

각 장 완성 후 아래를 확인한다.

- [ ] 슬라이드의 모든 상수·변수·판정 수치가 누락 없이 반영되었는가
- [ ] 슬라이드에 없는 수치를 임의로 만들지 않았는가
- [ ] 불릿을 그대로 옮긴 구간이 없는가
- [ ] 강의를 듣지 않은 독자가 혼자 완결할 수 있는가
- [ ] 모든 체크리스트 항목에 판정 가능한 통과 기준이 있는가
- [ ] 실습이 조별/개인 두 버전으로 제공되는가
- [ ] 다음 장 예고와 과제가 연결되는가
- [ ] 요약 카드만 봐도 장 전체가 복기되는가
- [ ] 위트가 금지 구역(상수·판정표·사례 결말)을 침범하지 않았는가
- [ ] 웃음의 대상이 직원이나 고객이 된 문장은 없는가
- [ ] 경영 개념을 미용 언어로 번역할 기회를 놓치지 않았는가
- [ ] 고정 은유 사전(3.6)과 어긋나게 쓴 비유는 없는가
- [ ] 한 장에 핵심 은유가 2개 이상 섞이지 않았는가
- [ ] 억지로 끼워 맞춘 비유는 없는가
