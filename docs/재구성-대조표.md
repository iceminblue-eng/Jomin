# 30장 한 권에서 세 권으로 — 무엇이 바뀌었는가

## 관리자론 — 헤어살롱 편 · 편집자 인수인계 대조표

기존 구성으로 작업하시던 원고를 새 구성에 맞추실 때 필요한 대조표입니다.

결론부터 말씀드리면 **본문 산문은 거의 그대로입니다.** 바뀐 1,040줄 중 **87%가 장 번호 · 부 표기 · 제목**이고, 실제로 문장이 달라진 곳은 **90줄**뿐입니다. 그 90줄이 어디인지도 아래에 전부 적어 두었습니다.

| 항목 | 값 |
| --- | --- |
| 원문 | 30장 · 1권 |
| 현재 | 51개 절 · 3권 |
| 신규 집필 | 17편 |
| 부록 실물 | 14종 |
| 문장 수정 | 90줄 |

# 2. 바뀐 1,040줄의 성격

재구성 전 원고와 현재 원고를 줄 단위로 대조한 결과입니다.

| 무엇이 바뀌었나 | 줄 | 비중 | 편집자가 할 일 |
| --- | --- | --- | --- |
| 장 번호 · 부 표기 참조 | 714 | **68.7%** | 찾아 바꾸기로 처리 가능 (4절 규칙) |
| 제목 줄 — 장 번호 재부여 | 163 | 15.7% | 대조표대로 번호만 교체 |
| **문장 수정** | **90** | **8.7%** | **직접 읽고 대조 — 3절에 전부 열거** |
| 머리말 인용 블록 (권 · 섹션 표기) | 42 | 4.0% | 절마다 한 줄, 형식 고정 |
| 부록 참조 (문자 → 권별 숫자) | 31 | 3.0% | 6절 대조표 |

**본문 산문은 손대지 않았습니다.** 사례, 상수 문장, 판정 수치, 표의 값은 전부 원문 그대로입니다. 기존 원고에 넣으신 교정은 대부분 그대로 살아 있습니다.

# 4. 기존 원고에 그대로 적용할 규칙

따로 작업하신 사본이 있으시면 이 순서로 처리하시면 같은 결과가 나옵니다.

## 규칙 1 · 장 번호

| 원문 | 처리 |
| --- | --- |
| 1~12장 | 번호 그대로, 1권 소속 |
| 13~22장 | 번호 **−12**, 2권 소속 (20장 → 2권 8장) |
| 23~30장 | 번호 **−22**, 3권 소속 (29장 → 3권 7장) |

표기는 **같은 권이면** `4장`, **다른 권이면** `2권 1장`, **권을 걸친 나열이면** `1권 3장 · 2권 8장`입니다. 범위는 `9~12장`, 나열은 `5 · 6 · 7장`으로 유지합니다.

## 규칙 2 · 부 표기

`제1부` `1부` → 1권 안에서는 `섹션 A`, 다른 권에서는 `1권 섹션 A`. 8개 부가 8개 섹션에 1:1로 대응합니다(1절 하단 표).

## 규칙 3 · 절 머리말

모든 절의 제목 아래 두 줄을 이 형식으로 통일했습니다.

```
> **관리자론 2 — 권한과 운영 · 섹션 B. 관리자가 실제로 돌리는 시스템**
> **적용 범위** 중대형 살롱(40평 이상 · 8인 이상) · 다점포(2개 지점 이상)
```

## 기계적 치환의 함정

> `1장 상수 4 · 4장 상수 4` 같은 문장에서 **상수 번호 4가 장 번호로 오인**됩니다.
>
> **상수 · 축 · 단계 · 규칙 · 원칙 · 문항 · 칸 · 조건 · 역량 · 요소 · 신호 · 경로 · 관문 · 층 · 순위 · 번** 뒤에 오는 숫자는 장이 아닙니다.
>
> 실제 작업에서 3건이 여기 걸렸습니다.
