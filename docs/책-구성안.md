| 항목 | 내용 |
| --- | --- |
| **상위 제목** | 관리자론 |
| **공통 분야 표기** | 헤어살롱 편 (세 권 모두 표지·판권에 유지) |

## 1. 시리즈를 관통하는 질문

> **좋은 관리자가 일할 수 있는 매장은 어떻게 만들어지는가?**

출발점은 관리자 개인의 능력 향상이 아니라, 관리자가 능력을 발휘할 수 있도록 **매장의 기준 · 역할 · 권한 · 평가 · 운영 체계를 설계**하는 데 있다.

| 구분 | 1권 | 2권 | 3권 |
| --- | --- | --- | --- |
| **제목** | 관리자론 1 — 기준과 진단 | 관리자론 2 — 권한과 운영 | 관리자론 3 — 확장과 양성 |
| **부제** | 우리 살롱에 맞는 관리자 모델을 설계하다 | 관리자가 일하고 시스템이 돌아가는 매장을 만들다 | 사람이 바뀌어도 이어지는 운영을 설계하다 |
| **권별 역할** | 매장을 진단하고 관리자 모델을 설계한다 | 권한과 신뢰를 바탕으로 운영을 작동시킨다 | 운영을 다른 사람과 지점에 이어 간다 |
| **핵심 질문** | 우리 매장에는 어떤 관리자가 필요한가? | 그 관리자는 무엇을 결정하고 무엇을 돌려야 하는가? | 그 사람이 없어도, 장소가 달라져도 유지되는가? |
| **독자 출발 상태** | 문제가 생길 때마다 사람을 바꾸려 한다 | 관리자는 있지만 결정이 원장에게 돌아온다 | 잘되는 방식이 특정 사람과 매장에 묶여 있다 |
| **독자가 얻는 판단** | 사람 문제와 구조 문제를 구분한다 | 위임 · 실행 · 기록 · 환류를 연결한다 | 재현 · 양성 · 승계의 준비 수준을 판단한다 |
| **권말 산출물** | 우리 매장 관리자 모델 결정서 | 우리 매장 운영 문서 세트 | 90일 실행 로드맵과 관리자 양성 계획 |
| **원문 범위** | 1~12장 + 막간 | 13~22장 | 23~30장 |
| **분량** | 19개 절 · 179쪽 | 15개 절 · 133쪽 | 14개 절 · 133쪽 |

**연속 서사** — 기준을 찾는다 → 권한을 준다 → 매일 돌린다 → 기록에서 배운다 → 사람을 키운다 → 다른 자리에서도 재현한다.

### 권별 결말 문장

- **1권** 우리 매장에 어떤 관리자가 필요한지, 그 이유를 말할 수 있다.
- **2권** 그 관리자가 어디까지 결정하고 무엇을 돌려야 하는지, 문서와 행동으로 보여 줄 수 있다.
- **3권** 그 운영을 다음 사람에게 이어 주고, 우리 매장의 다음 실행을 정할 수 있다.

## 2. 권별 구성

### 1권 · 기준과 진단 (19개 절)

| 위치 | 절 |
| --- | --- |
| **권두** | 총서문 「미용실에는 왜 운영 매뉴얼이 없을까」 · 프롤로그 「관리자를 세우기 전에」 · 용어 「이 책의 말을 미용 말로」 |
| **섹션 A. 관리자가 필요한 이유를 다시 묻다** | 1장 관계가 아니라 구조로 / 2장 역할 경계 / 3장 관리자 KPI |
| **섹션 B. 우리 살롱의 좌표를 찾다** | 4장 3층 문법 / 5장 구조 좌표 / 6장 조직 좌표 / 7장 사람 좌표 / 8장 운영 코드 / **막간 상수 헌장 10선** |
| **섹션 C. 우리 매장의 관리자 모델을 선택하다** | 9장 선수형 / 10장 오피스형 / 11장 복수·혼합형 / 12장 모델 결정 |
| **권말** | 권말 실습 「관리자 모델 결정서」 · 에필로그 「이제 선택의 이유를 말할 수 있습니다」 · 2권 예고 「어디까지 맡기셨습니까」 |

*8장 운영 코드와 막간 상수 헌장은 서로 연결되므로 떨어뜨리지 않는다. 권말 실습에 **최소 권한 확인표**를 붙여 2권 없이도 시험운영의 전제조건을 이해하게 했다.*

### 2권 · 권한과 운영 (15개 절)

| 위치 | 절 |
| --- | --- |
| **권두** | 입구 「이 권부터 읽는 분께」(핵심 개념 4 + 간이 인테이크) · 프롤로그 「맡긴다는 말에는 내용이 필요합니다」 |
| **섹션 A. 관리자가 결정할 수 있는 조건** | 1장 권한 없는 책임 / 2장 예측 가능성 / 3장 이원 리더십 / 4장 갈등 조정 |
| **섹션 B. 관리자가 실제로 돌리는 시스템** | 5장 하루 리듬 / 6장 고객 운영 / 7장 선수 운영 / 8장 숫자·돈·자원 / 9장 보고와 회의 / 10장 변수 대응 |
| **권말** | 권말 실습 「운영 문서 연결 점검」 · 에필로그 「같은 문제를 다시 만났을 때」 · 3권 예고 「누가 이어받을 수 있습니까」 |

*8장 지표 정의 → 9장 회의 → 10장 반복 문제의 기준 개정 순서는 반드시 유지한다. 권말 실습은 문서 개수가 아니라 **다섯 개 연결 고리가 도는지**를 점검한다.*

### 3권 · 확장과 양성 (14개 절)

| 위치 | 절 |
| --- | --- |
| **권두** | 리캡 「우리가 여기까지 온 과정」 · 입구 「이 권부터 읽는 분께」(최소 도구 6) · 프롤로그 「같은 간판 아래, 다른 좌표」 |
| **섹션 A. 운영을 다른 지점에 이어 가다** | 1장 표준화·현지화 / 2장 거버넌스 / 3장 비교 학습 |
| **섹션 B. 운영을 다음 사람에게 이어 주다** | 4장 관리자 선발 / 5장 6개월 양성 / 6장 평가·보상·커리어 |
| **섹션 C. 우리 매장의 다음 실행을 정하다** | 7장 케이스 처방 / 8장 90일 로드맵 |
| **권말** | 권말 실습 「다음 실행을 정한다」 · 에필로그 「다음 사람이 이어 쓸 수 있도록」 · 마무리 「다음 장은 우리 매장에서」 |

*3권은 완결권이므로 4권을 예고하지 않는다. 결론은 지점 확대가 아니라 **확장할 수 있는가 / 더 준비해야 하는가 / 단일점 승계부터 설계해야 하는가**를 판단하는 능력이다.*

**읽는 경로** — 단일점: 리캡 → 4~6장 → 7장 → 8장 (1~3장은 승계·확장 검토 시 연결) / 다점포: 리캡 → 1~3장 → 4~6장 → 7장 → 8장

## 3. 독립성과 연속성 장치

1. **각 권에 입구를 둔다.** 후속 권 독자에게 이전 책을 요구하지 않고, 실습에 필요한 최소 개념과 빈 양식을 제공한다. 간이 진단은 정밀 판정을 대신하지 않는다고 명시한다.
2. **같은 문서를 다음 권에서 발전시킨다.** 1권 운영 코드·역할 헌장 → 2권 권한 위임·운영 설계 → 2권 변수 로그·반복 문제 목록 → 3권 양성 프로젝트·케이스 처방·90일 로드맵.
3. **각 권의 결말은 그 권의 약속을 먼저 완수한다.** 다음 권 소개는 완결 뒤에 별도 페이지로 배치한다.
4. **사례를 하나의 실화로 합치지 않는다.** 연속성은 동일 인물의 성공담이 아니라 독자가 자기 매장을 읽는 방식의 변화로 만든다.
5. **원문 8개 '부'는 권 안의 '섹션'으로 바꾼다.** '3부작의 3부'와 '원문 제3부'의 혼동을 막는다.

## 4. 편집 규약

### 참조 표기

각 권의 장 번호는 1장부터 시작한다.

| 상황 | 표기 |
| --- | --- |
| 같은 권 안 | `4장`, `5 · 6 · 7장`, `9~12장` |
| 다른 권 | `2권 1장`, `3권 1 · 2장` |
| 혼합 | `1권 3장 · 2권 8장` |

*원문 → 신 번호 대응: 1~12장은 1권에서 번호 유지 / 13~22장 → 2권 1~10장 / 23~30장 → 3권 1~8장.*

### 유지할 반복

상수·준상수·변수의 구분 / 좌표가 다르면 처방이 다르다 / 권한 없는 책임 / 개인 성과와 조직 성과의 구분 / 기록·집계·개정의 환류 / 원장과 관리자 부재 시 유지되는 품질.

### 제거한 것

- 강의 회차·종강·강의실을 전제한 표현 (24건)
- "이 책에서 몇 번째 나오는 문장"처럼 단권 독서 순서를 전제한 표현 (5건)
- 조별 수업 표기 → **공동 실습**으로 통일 (39건)
- 권 경계에 걸린 '다음 부 예고' 절 → 전용 브리지 페이지로 대체 (2건)

*'혼자 읽는 독자를 위한 버전'은 전 절에서 보존한다.*

## 5. 저자 확인이 필요한 항목

아래는 원문의 논리를 보존하기 위해 **임의로 답을 정하지 않고 남겨 둔** 항목이다.

| 항목 | 원문에서 확인된 지점 | 제안 |
| --- | --- | --- |
| **2층 설명과 3층 설명** | 초기에는 '상수×변수', 4장부터 준상수를 분리 | 권두에서 "초기에는 넓은 의미의 변수로 설명하고, 이후 준상수와 일상 변수로 구분한다"고 안내 |
| **1권 12장 점수 검산** | 70평 사례의 시스템 점수 8에 대해 편집자 주가 배점상 6임을 지적 | 확인 대상으로 남김. 배점대로 6을 적용해도 **Q2 판정은 유지**됨을 명시 |
| **사분면과 조직 배치** | 같은 사례에서 기술 리더와 오피스형을 함께 두며 Q2→Q3 이동으로 서술 | 진단 사분면과 실제 인력 조합을 구분. 기술 리더가 있다고 두 복잡도가 모두 높아지는지 확인 |
| **공동 결정의 예외** | 1권 2장은 단일 결정권자, 11장은 일부 공동 영역 | 사전 기준·합의 불가 시 이관이라는 예외 조건을 함께 보존 |
| **세 종류의 90일** | 10장 제도 신설 최소화 / 12장 모델 시험운영 / 3권 8장 시스템 구축 | 적용 대상과 시작 시점을 별도 표로 구분. 10장 제도 유예와 3권 8장 31~60일 가동의 관계는 저자 확인 후 통일 |
| **헌장 선정과 개념 분류** | 막간에 헌장 비선정 항목을 '준상수로 내린다'는 표현 | 헌장에 싣지 않는 것과 개념상 준상수인 것을 구분할지 확인 |
| **예외 공개와 사생활 보호** | 2권 2장의 예외 공개, 1권 7장·2권 4장의 사생활 보호 | 공개 대상은 적용 기준과 결정 근거이며 개인 사정의 상세 공개와 다르다는 연결 설명 |
| **금전 사안과 전결** | 비용 한도 내 전결과 금전 사고의 즉시 이관이 함께 제시됨 | 일반 비용 집행과 사고·한도 초과 이관 사안을 구분 |
| **비슷한 숫자의 다른 의미** | 선수형 평가 비중, 관리 시간 비율, 개인 매출 집중도에 유사 수치 | 각 표에 분자·분모·용도를 명시. 같은 30%를 하나의 규칙으로 합치지 않는다 |
| **경험칙과 사례 수치** | 규모·인원·부하 진단 기준과 사례 결과 | 저자의 운영 판단 기준과 사례 수치로 표기. 일반 통계나 보장된 성과로 확장하지 않는다 |
| **부록 A~K** | 목록과 완성 지점은 확정, 실물 양식 미제작 | 권별 부록 번호로 재정리 후 제작 |
