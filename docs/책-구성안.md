# 『관리자론 — 헤어살롱 편』 구성안

> 부제(안): **미용 시장 관리자 운용 바이블**
> 원본: 「운영 관리자 · 매트릭스 대입 수업」 발표용 강의안

## 1. 기획 요약

| 항목 | 내용 |
| --- | --- |
| **대상 독자** | 중대형 살롱 원장(40평 이상 · 8인 이상) · 다점포 원장(2개 지점 이상) · 총괄 관리자를 지향하는 관리자 |
| **핵심 프레임** | **운영 관리자 매트릭스 = 상수 × 준상수 × 변수** |
| **책의 약속** | 남의 매장 사례를 복사하는 책이 아니라, **우리 매장의 좌표를 진단하고 답을 도출하는 책** |
| **형식** | 읽는 책 + 찾아보는 책. 장마다 진단 도구·판정 기준·실행 양식을 포함 |
| **규모** | **30장 + 막간 1 + 부록 A~K** · 8개 부 · 상수 120개 (전권 초고 완료) |

### 매트릭스 한 장 요약 (4장)

```
입력 · 좌표              처리 · 3층 문법          출력 · 운영 설계
구조 좌표 (5장)          상수                    관리자 유형 (3부)
조직 좌표 (6장)     →    준상수             →    권한·역할 헌장 (4부)
사람 좌표 (7장)          변수                    KPI 스코어카드 (3장)
        ▲                                                │
        └── 환류: 반복되는 변수는 상수 개정으로 (22장) ──┘
```

## 4. 책 전체를 관통하는 상수

각 장에서 확정된 상수는 이후 전 장에서 유지됩니다. 현재 **104개**.

**1장 · 구조 진단**
1. 구조 진단이 관리자 채용보다 먼저다
2. 기준은 문서로 존재해야 한다
3. 같은 상황에는 같은 답
4. 예외는 기록된다

**2장 · 역할 경계**
5. 역할은 사람이 아니라 자리에 부여한다
6. 하나의 업무에는 하나의 결정권자만 존재한다
7. 원장은 팀원에게 직접 지시하지 않는다
8. 권한 없는 책임을 만들지 않는다

**3장 · 관리자 평가**
9. 개인 매출과 조직 성과를 분리해서 집계한다
10. 조직 성과는 4축을 모두 포함한다
11. 개인 매출에는 상한 비중을 둔다
12. '부재 시 품질 유지'를 정기적으로 측정한다

**4장 · 분류 문법**
13. 새 문제 앞에서 규정 신설은 마지막 수단이다
14. 상수는 소수 정예로 유지한다

> ✅ **4장 상수 2와의 충돌 — 「막간 · 우리 매장 상수 헌장 10선」으로 해소**
> 4장은 "상수는 10여 개를 넘으면 규정집"이라고 규정하고, 책 전체는 **120개**입니다.
> 이는 **책의 상수 목록**(교육용 전체)과 **한 매장의 상수 헌장**(10여 개로 압축)이 다른 층위이기 때문입니다.
> **8장 확인 결과:** 운영 코드는 좌표를 압축하지만 **상수 선별 절차는 포함하지 않습니다.**
> **부록 A~K 전수 확인 완료 (26장 시점):** 열한 개 부록 중 **좌표별 상수 선별 기능을 맡은 것이 없습니다.**
> **23장이 부분적 해답을 제시합니다** — 브랜드 상수 10개로 압축하는 절차가 다점포 맥락에서 나옵니다.
> 다만 **단일점 독자를 위한 절차는 여전히 없습니다.**
> **해소 방식:** 8장 직후에 **제2부 막간**을 신설했습니다. 두 층위를 명시적으로 갈랐습니다.
> — **책의 상수 120개 = 약장.** 어떤 좌표의 매장에도 대응하기 위한 교육 목록.
> — **우리 매장 헌장 10개 = 트레이.** 이 매장이 실제로 지키는 실행 목록.
>
> **막간이 채우는 공백:** 4장 워크시트는 *안에서 밖으로*(우리 기존 규칙 → 압축)만 다뤘고, 23장 브랜드 상수는 판별 질문이 *지점 간 비교*에 의존해 단일점에서 작동하지 않았습니다.
> 막간은 *밖에서 안으로*(책의 상수 120개 → 우리 좌표가 요구하는 것) 방향을 담당하며, 단일점 판별선을 **"이 원칙이 깨진 날 고객이 알아차리는가"**로 두어 지점 수와 무관하게 작동합니다.
>
> **막간은 새 상수를 추가하지 않습니다.** 선별 관문은 상수가 아니라 규칙(R1~R4)으로 명명했습니다.
> 상수 총계는 120개로 유지됩니다 — 상수 과다를 다루는 절이 상수를 늘리면 자기모순이기 때문입니다.
