## 1. 기획 요약

| 항목 | 내용 |
| --- | --- |
| **대상 독자** | 중대형 살롱 원장(40평 이상 · 8인 이상) · 다점포 원장(2개 지점 이상) · 총괄 관리자를 지향하는 관리자 |
| **핵심 프레임** | **운영 관리자 매트릭스 = 상수 × 변수** |
| **책의 약속** | 남의 매장 사례를 복사하는 책이 아니라, **우리 매장의 좌표를 진단하고 답을 도출하는 책** |
| **형식** | 읽는 책 + 찾아보는 책. 장마다 진단 도구·판정 기준·실행 양식을 포함 |

### 상수 × 변수란

- **상수** — 규모·상권·인원·컨셉과 무관하게 유지되는 원칙. **복사 가능.**
- **변수** — 우리 매장의 평수·인원·상권·고객층·원장 성향. **복사 불가, 진단 대상.**

세미나 조언이 우리 매장에서 안 먹히는 이유는 **남의 변수를 복사하기 때문**이다. 이 책은 상수를 고정하고 그 위에 독자의 변수를 대입시킨다.

## 3. 1장이 책 전체에서 하는 역할

1장은 **진단의 시작점**이며, 뒤의 모든 장으로 가는 분기점이다.

```
1장 · 상수가 없는 상태를 식별한다
   │
   ├─ Q1 기준 문서 절반 미만 ──→ 제1부 2~3장 (역할 경계 · 구조 문서화)
   ├─ Q2 부재 72시간 실패 ────→ 13장 (권한 위임 설계)
   ├─ Q3 구조 언어 부재 ──────→ 제2부 4~8장 (좌표 진단)
   └─ 세 관문 통과 ───────────→ 제3부 9~12장 (관리자 유형 선택)
```

따라서 **1장은 독립적으로 읽혀도 완결**되어야 하고, 동시에 **네 방향의 입구**를 정확히 열어 주어야 한다.

---

## 4. 책 전체를 관통하는 상수

1장에서 확정된 네 상수는 **전 장에서 예외 없이 유지**된다.

1. 구조 진단이 관리자 채용보다 먼저다 — 순서는 바뀌지 않는다
2. 기준은 문서로 존재해야 한다 — 머릿속 기준은 기준이 아니다
3. 같은 상황에는 같은 답 — 사람이 바뀌어도 답은 유지된다
4. 예외는 기록된다 — 기록 없는 예외는 원칙 붕괴의 시작이다
