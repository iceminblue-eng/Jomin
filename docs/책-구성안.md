# 『관리자론 — 헤어살롱 편』 구성안

> 부제(안): **미용 시장 관리자 운용 바이블**
> 원본: 「운영 관리자 · 매트릭스 대입 수업」 발표용 강의안

## 1. 기획 요약

| 항목 | 내용 |
| --- | --- |
| **대상 독자** | 중대형 살롱 원장(40평 이상 · 8인 이상) · 다점포 원장(2개 지점 이상) · 총괄 관리자를 지향하는 관리자 |
| **핵심 프레임** | **운영 관리자 매트릭스 = 상수 × 준상수 × 변수** |
| **책의 약속** | 남의 매장 사례를 복사하는 책이 아니라, **우리 매장의 좌표를 진단하고 답을 도출하는 책** |
| **형식** | 읽는 책 + 찾아보는 책. 장마다 진단 도구·판정 기준·실행 양식을 포함 |
| **규모** | 최소 **29장 + 부록 A~J** (강의안 상호 참조로 확인) |

### 매트릭스 한 장 요약 (4장)

```
입력 · 좌표              처리 · 3층 문법          출력 · 운영 설계
구조 좌표 (5장)          상수                    관리자 유형 (3부)
조직 좌표 (6장)     →    준상수             →    권한·역할 헌장 (4부)
사람 좌표 (7장)          변수                    KPI 스코어카드 (3장)
        ▲                                                │
        └── 환류: 반복되는 변수는 상수 개정으로 (22장) ──┘
```

## 2. 전체 목차

### 제1부 · 원장과 관리자를 분리하라 (1~3장)

| 장 | 제목 | 매트릭스 위치 | 상태 |
| --- | --- | --- | --- |
| **1장** | 규모가 커지면 관계가 아니라 구조로 운영해야 한다 | 진단의 필요 | ✅ 원고 완료 |
| **2장** | 원장·관리자·팀원의 역할은 어떻게 달라야 하는가 | 상수 확정 ① | ✅ 원고 완료 |
| **3장** | 운영 관리자의 성과는 개인 매출만으로 평가할 수 없다 | 출력 정의 | ✅ 원고 완료 |

| **5장** | 구조 좌표: 규모·상권·지점 수가 운영 방식을 결정한다 | 준상수 대입 ① | ✅ 원고 완료 |
| **6장** | 조직 좌표: 인원수와 구성원 조합을 읽어라 | 준상수 + 변수 | ✅ 원고 완료 |

## 4. 책 전체를 관통하는 상수

각 장에서 확정된 상수는 이후 전 장에서 유지됩니다. 현재 **64개**.

**1장 · 구조 진단**
1. 구조 진단이 관리자 채용보다 먼저다
2. 기준은 문서로 존재해야 한다
3. 같은 상황에는 같은 답
4. 예외는 기록된다

**2장 · 역할 경계**
5. 역할은 사람이 아니라 자리에 부여한다
6. 하나의 업무에는 하나의 결정권자만 존재한다
7. 원장은 팀원에게 직접 지시하지 않는다
8. 권한 없는 책임을 만들지 않는다

**3장 · 관리자 평가**
9. 개인 매출과 조직 성과를 분리해서 집계한다
10. 조직 성과는 4축을 모두 포함한다
11. 개인 매출에는 상한 비중을 둔다
12. '부재 시 품질 유지'를 정기적으로 측정한다

**4장 · 분류 문법**
13. 새 문제 앞에서 규정 신설은 마지막 수단이다
14. 상수는 소수 정예로 유지한다
15. 준상수는 측정 주기를 갖는다
16. 변수는 반드시 기록된다

**5장 · 구조 좌표**
17. 평수는 관리 방식을 바꾼다
18. 상권은 전략축을 정한다
19. 구조 좌표는 읽는 대상이다
20. 좌표가 바뀌면 운영 블록을 교체한다

**6장 · 조직 좌표**
21. 인원수가 아니라 업무 복잡도로 조직을 센다
22. 구성비는 준상수, 개별 입퇴사는 변수다
23. 한 사람에게 조직이 걸리지 않게 한다
24. 비즈니스 유형에 따라 모든 관리 기준을 다르게 세운다

**7장 · 사람 좌표**
25. 사람 좌표는 평가가 아니라 조직 설계 정보다
26. 관리자는 원장의 사각지대를 메우는 사람이다
27. 위임 수준은 연차에 맞춰 단계적으로 올린다
28. 사생활 영역은 기록하지 않는다

**8장 · 진단**
29. 진단 없이 처방하지 않는다
30. 지점마다 코드를 따로 부여한다
31. 코드는 분기마다 재측정한다
32. 코드는 숫자와 근거로 쓴다

**9장 · 선수형**
33. 관리 시간을 예약표에 먼저 확보한다
34. 주간 시술 시간에 상한을 둔다
35. 현장 감각은 문서와 데이터로 전환해 남긴다
36. 전환 신호가 오면 유형을 바꾼다

**10장 · 오피스형**
37. 기술 영역은 침범하지 않는다
38. 매일 현장에 선다
39. 제도는 현장 검토를 거쳐 시행한다
40. 성과는 팀의 이름으로 돌린다

**11장 · 복수·혼합형**
41. 두 관리자를 경쟁시키지 않는다
42. 공동 결정 영역을 문서로 명시한다
43. 충돌은 조율 회의에서 다루고 결론은 한 목소리로
44. 혼합형은 시간 비율을 숫자로 고정한다

**12장 · 유형 결정**
45. 유형은 좌표가 정한다
46. 결정은 반드시 90일 시험운영으로 검증한다
47. 경제성은 인건비가 아니라 운영 손실로 계산한다
48. 좌표가 바뀌면 유형도 바꾼다

**13장 · 권한 설계**
49. 책임을 맡길 때는 권한을 함께 준다
50. 승인 한도는 금액과 사안으로 문서화한다
51. 한도 내 결정은 결과가 나빠도 존중한다
52. 이견은 팀원 앞이 아니라 1:1에서 다룬다

**14장 · 팀원 관계**
53. 같은 상황에는 같은 답 (사람·기분·바쁨 무관)
54. 예외는 사실과 이유를 공개한다
55. 칭찬은 공개, 지적은 개별
56. 피드백은 다음 행동까지 준다

**15장 · 이원 리더십**
57. 인턴에게 지시하는 경로는 하나로 정한다
58. 기술 평가와 조직 기여 평가를 분리한다
59. 커리큘럼은 운영 리더가, 지도는 기술 리더가
60. 고객은 매장의 자산이다

**16장 · 갈등 조정**
61. 이견은 1:1에서, 반대는 대안과 함께
62. 인기 디자이너에게도 같은 기준
63. 갈등은 구조 언어로 기록한다
64. 혼자 지지 않는다 — 에스컬레이션 기준을 미리 정한다

> ⚠️ **4장 상수 14와의 충돌 주의**
> 4장은 "상수는 10여 개를 넘으면 규정집"이라고 규정합니다. 현재 64개입니다.
> 이는 **책의 상수 목록**(교육용 전체)과 **한 매장의 상수 헌장**(10여 개로 압축)이 다른 층위이기 때문입니다.
> **8장 확인 결과:** 운영 코드는 좌표를 압축하지만 **상수 선별 절차는 포함하지 않습니다.**
> **12장 확인 결과:** 부록 B는 「관리자 유형 선택 점수표」로 확정 — 앞서 제안했던 부록 B 활용안은 폐기합니다.
> 현재 확인된 부록 A~H·J 중 이 기능을 맡을 자리가 없습니다. **미확인 부록 I** 또는 **신설**이 필요합니다.
> **저자 확인 필요 사항:** ① 부록 I의 내용 ② 좌표별 상수 선별 절차의 존재 여부.
> 없다면 책에서 신설을 제안합니다 — 8장 운영 코드 다음에 「우리 매장 상수 헌장 10선」 절을 붙이는 방식.
