# 『관리자론 — 헤어살롱 편』 구성안

> 부제(안): **미용 시장 관리자 운용 바이블**
> 원본: 「운영 관리자 · 매트릭스 대입 수업」 발표용 강의안

---

## 1. 기획 요약

| 항목 | 내용 |
| --- | --- |
| **대상 독자** | 중대형 살롱 원장(40평 이상 · 8인 이상) · 다점포 원장(2개 지점 이상) · 총괄 관리자를 지향하는 관리자 |
| **핵심 프레임** | **운영 관리자 매트릭스 = 상수 × 준상수 × 변수** |
| **책의 약속** | 남의 매장 사례를 복사하는 책이 아니라, **우리 매장의 좌표를 진단하고 답을 도출하는 책** |
| **형식** | 읽는 책 + 찾아보는 책. 장마다 진단 도구·판정 기준·실행 양식을 포함 |
| **규모** | 최소 **29장 + 부록 A~J** (강의안 상호 참조로 확인) |

### 매트릭스 한 장 요약 (4장)

```
입력 · 좌표              처리 · 3층 문법          출력 · 운영 설계
구조 좌표 (5장)          상수                    관리자 유형 (3부)
조직 좌표 (6장)     →    준상수             →    권한·역할 헌장 (4부)
사람 좌표 (7장)          변수                    KPI 스코어카드 (3장)
        ▲                                                │
        └── 환류: 반복되는 변수는 상수 개정으로 (22장) ──┘
```

## 2. 전체 목차

### 제1부 · 원장과 관리자를 분리하라 (1~3장)

| 장 | 제목 | 매트릭스 위치 | 상태 |
| --- | --- | --- | --- |
| **1장** | 규모가 커지면 관계가 아니라 구조로 운영해야 한다 | 진단의 필요 | ✅ 원고 완료 |
| **2장** | 원장·관리자·팀원의 역할은 어떻게 달라야 하는가 | 상수 확정 ① | ✅ 원고 완료 |
| **3장** | 운영 관리자의 성과는 개인 매출만으로 평가할 수 없다 | 출력 정의 | ✅ 원고 완료 |

*3장이 1부 완결 회차. 1부에서 매트릭스의 뼈대를 한 바퀴 돈다.*

### 제2부 · 상수와 변수로 우리 살롱의 좌표를 찾아라 (4~8장)

| 장 | 제목 | 매트릭스 위치 | 상태 |
| --- | --- | --- | --- |
| **4장** | 경우의 수가 많을수록 상수를 굵게 만들어라 | 문법 학습 | ✅ 원고 완료 |
| **5장** | 구조 좌표: 규모·상권·지점 수가 운영 방식을 결정한다 | 준상수 대입 ① | ✅ 원고 완료 |
| **6장** | 조직 좌표: 인원수와 구성원 조합을 읽어라 | 준상수 + 변수 | ✅ 원고 완료 |
| **7장** | 사람 좌표: 원장 배경·연차·세대 | 준상수 대입 ③ | 강의안 대기 |
| **8장** | 인테이크: 세 좌표를 통합해 '운영 코드'를 만든다 | 입력 완성 | 강의안 대기 |

### 제3부 · 관리자 유형 (9~12장)

| 장 | 확인된 내용 | 상태 |
| --- | --- | --- |
| 9~12장 | 선수형 · 오피스형 · 혼합형 판정과 설계 | 강의안 대기 |
| **10장** | 오피스형 KPI (시스템·숫자 성과) — *3장 R2에서 참조* | 강의안 대기 |

### 제4부 · 권한과 역할 헌장 (13장~)

| 장 | 확인된 내용 | 상태 |
| --- | --- | --- |
| **13장** | 권한 위임 설계 — *1장 Q2에서 참조* | 강의안 대기 |

### 이후 확인된 장 (강의안 상호 참조에서)

| 장 | 내용 | 참조 출처 |
| --- | --- | --- |
| **17장** | 하루 운영 리듬 | 5장 과제 |
| **18장** | 고객 운영 전략 | 5장 과제 · 6장 과제 |
| **20장** | KPI 공통 정의 (지표별 정의·계산식) | 3장 도구 |
| **22장** | 변수 대응 (변수 로그 최종 분석) | 4장 매트릭스 · 4장 과제 |
| **28장** | 보상 연동 | 3장 도구 |
| **29장** | 케이스 처방 | 4장 학습 목표 |

### 부록

| 부록 | 내용 | 참조 출처 |
| --- | --- | --- |
| **A** | 진단 인테이크 | 4장 · 5장 · 6장 도구 |
| **C** | 원장-관리자 1페이지 역할 헌장 | 2장 도구 |
| **D** | 의사결정권 · 승인 한도 표 | 2장 도구 |
| **F** | (KPI 관련) | 3장 도구 |
| **J** | (보상 관련) | 3장 도구 |

> ⚠️ 제3·4부의 개별 장 제목과 부록 B·E·G·H·I는 아직 미확인입니다.
> 위 표는 **1~6장 강의안에 실제로 등장한 상호 참조만** 정리한 것이며, 추측은 포함하지 않았습니다.

## 3. 장 간 연결 지도

각 장의 과제 산출물이 다음 장의 입력이 되도록 설계되어 있습니다.

| 장 | 과제 산출물 | 쓰이는 곳 |
| --- | --- | --- |
| 1장 | 체크리스트 점수 · 공백 목록 · 한 문장 상수 | 2장 오프닝 |
| 2장 | 역할 헌장 초안 · **직접 지시 카운트** | 3장 오프닝 |
| 3장 | 스코어카드 · **시간 사용 기록** · 부재 실험 | 4장 오프닝 |
| 4장 | 3층 분류표 · 상수 헌장 초안 · **변수 로그** | 5~8장 전체 · 22장 |
| 5장 | 구조 좌표 시트 · **피크 점유율** | 8장 · 17장 · 18장 |
| 6장 | 조직 좌표 시트 · **유형 판정문** | 8장 운영 코드 · 18장 |

## 4. 책 전체를 관통하는 상수

각 장에서 확정된 상수는 이후 전 장에서 유지됩니다. 현재 **20개**.

**1장 · 구조 진단**
1. 구조 진단이 관리자 채용보다 먼저다
2. 기준은 문서로 존재해야 한다
3. 같은 상황에는 같은 답
4. 예외는 기록된다

**2장 · 역할 경계**
5. 역할은 사람이 아니라 자리에 부여한다
6. 하나의 업무에는 하나의 결정권자만 존재한다
7. 원장은 팀원에게 직접 지시하지 않는다
8. 권한 없는 책임을 만들지 않는다

**3장 · 관리자 평가**
9. 개인 매출과 조직 성과를 분리해서 집계한다
10. 조직 성과는 4축을 모두 포함한다
11. 개인 매출에는 상한 비중을 둔다
12. '부재 시 품질 유지'를 정기적으로 측정한다

**4장 · 분류 문법**
13. 새 문제 앞에서 규정 신설은 마지막 수단이다
14. 상수는 소수 정예로 유지한다
15. 준상수는 측정 주기를 갖는다
16. 변수는 반드시 기록된다

**5장 · 구조 좌표**
17. 평수는 관리 방식을 바꾼다
18. 상권은 전략축을 정한다
19. 구조 좌표는 읽는 대상이다
20. 좌표가 바뀌면 운영 블록을 교체한다

**6장 · 조직 좌표**
21. 인원수가 아니라 업무 복잡도로 조직을 센다
22. 구성비는 준상수, 개별 입퇴사는 변수다
23. 한 사람에게 조직이 걸리지 않게 한다
24. 비즈니스 유형에 따라 모든 관리 기준을 다르게 세운다

> ⚠️ **4장 상수 14와의 충돌 주의**
> 4장은 "상수는 10여 개를 넘으면 규정집"이라고 규정합니다. 현재 24개입니다.
> 이는 **책의 상수 목록**(교육용 전체)과 **한 매장의 상수 헌장**(10여 개로 압축)이 다른 층위이기 때문입니다.
> 8장 운영 코드에서 좌표별로 **어떤 상수를 헌장에 올릴지 선별**하는 절차가 필요합니다. 8장 강의안 수령 시 확인할 것.
