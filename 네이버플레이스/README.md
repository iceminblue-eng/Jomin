# 네이버 플레이스 전략 기획 시스템

성공 브랜드의 플레이스 셋팅값을 근거로 **"최적화된 네이버 플레이스"의 정의와 기준점**을 세우고,
새 브랜드를 그 기준에 대입해 **보완점**과 **개선점**을 도출하는 작업 폴더입니다.

| 항목 | 내용 |
| --- | --- |
| 적용 대상 | 헤어살롱 **고객수 비즈니스** (월 신규 450명 · 객단가 6~7만원 구조) |
| 타입 ① | **프랜차이즈 고객수** — 기준 A 이가자헤어비스 신도림점 · 기준 B 로한(디얼스 목동41타워점) |
| 타입 ② | **지역 로컬 고객수** — 기준 L 온앤어스헤어 불당점 (천안) |
| 타입 ③ | **상위 가격대 (객단가 8~9만원)** — 기준 P 아이디헤어 대치점 (잠정). 6~7만원 가격 방정식을 8~9만원으로 다시 도출한 별도 기준 (기준 문서 §0-4) |
| 기준 문서 | [`00-정의-및-최적화-기준.md`](00-정의-및-최적화-기준.md) v1.3 — 타입 체계 · 정의 · 타입별 기준값 · 32항목 · 판정 규칙 · KPI |
| 사례 | 온앤어스헤어 불당점 (2026-08-21, 로컬) · 아이디헤어 대치점 (2026-09-11, 상위 가격대) — 진단 리포트 수록 |

## 새 브랜드가 들어왔을 때 (진단 절차)

| 단계 | 하는 일 | 산출물 |
| --- | --- | --- |
| 1 | 플레이스 전 탭(홈·소식·가격·예약·스타일·리뷰·사진·지도·정보)을 **같은 날** 캡처. 원자료는 `02-비교브랜드/브랜드명-원자료/`에 | 캡처 세트 + 스냅샷 일자 |
| 2 | `_양식-브랜드-카드.md`를 복사해 `02-비교브랜드/브랜드명.md` 작성. **비즈니스 타입**을 먼저 정한다(기준 문서 §0-2 판별 질문). [정량 지표]·[32항목 체크] 두 표는 구조를 바꾸지 않고 값만 채운다 | 브랜드 카드 (타입 지정) |
| 3 | `python3 tools/naver_place_gap.py 네이버플레이스/02-비교브랜드/브랜드명.md -o 네이버플레이스/03-분석보고서/브랜드명-YYYYMMDD.md` — 카드의 타입 행을 읽어 그 타입의 기준값을 쓴다 (`--type 프랜차이즈|로컬|프리미엄` 로 강제 가능) | 리포트 뼈대 (정량 GAP · 퍼널 · 가격 3단 · 9영역 판정 · P0/P1/P2 목록 · 강점 · 로드맵 틀) |
| 4 | 뼈대의 `_` 칸을 채운다: 한 줄 결론(매장 유형) · 우선순위 5 · 처방 문안(기준 문서 §9 문형) · 개선점 · 로드맵 담당/기한 | 완성 리포트 |
| 5 | 매장 전달용 리포트를 쓴다: 기준 브랜드명 대신 **'프랜차이즈형 고객수 비즈니스 타입 기준'**으로 표기, P0/P1/P2 대신 **1·2·3개월 차(30일 단위)** 플랜, '~보완이 필요해요' 문장, 항목마다 캡처 크롭 이미지(`산출물/이미지/브랜드명/`). 내부 진단(브랜드명·P등급)은 `-내부진단.md`로 보존 | 전달용 리포트 |
| 6 | `bash tools/naver_place_build.sh 리포트.md 카드.md` → Word 리포트와 Excel 기입 시트를 `03-분석보고서/산출물/`에 생성. 매장에는 이 두 파일을 전달한다 | .docx · .xlsx |
| 7 | 매장이 Excel의 노란 칸(담당·목표일·상태·실제 적용 문구·재점검 충족)을 채워 돌려주면 → 카드 갱신 → 스크립트 재실행 → 리포트 v2. §9 제안은 `00-정의` 개정에 반영 | 재점검 리포트 · 기준 문서 다음 버전 |

## 출력의 뜻

| 용어 | 뜻 | 판정 근거 |
| --- | --- | --- |
| **보완점** | 기준 **미달**. 기준까지 채우는 것이 목표 | 32항목 N/부분 · 정량 달성률 100% 미만 · 영역 시급/보완 |
| **개선점** | 기준 **충족**했으나 상위 수준과 격차. 상위 = 프랜차이즈 타입은 B(로한), 로컬 타입은 A(이가자) | 정량 자기 타입 기준 이상 상위값 미만 · 체크 Y이나 최상급 패턴과 차이 |
| **유지** | 상위 수준과 동등 이상 | 강점으로 기록, 표준화 대상 |
| P0 / P1 / P2 | 전환 장치(14일) / 콘텐츠 포화(30일) / 운영 루틴(90일) | 기준 문서 §5-2 |

## 자료를 줄 때

캡처·메모·표·링크 어느 형식이든 됩니다. 카드를 바로 채우려면 아래가 있으면 좋습니다.

1. 업체명 · 지역 · 상권, 캡처 일자
2. 홈: 대표사진, 대표 배지가 붙은 상품과 가격, 평점, 방문자·블로그 리뷰 수
3. 가격 탭: 상품명(라벨 포함) · 가격 전부, 추가요금 표기 여부, 가격표 이미지 수
4. 쿠폰 탭: 쿠폰명 · 혜택 · 조건 전부
5. 예약 탭: 상품 목록과 각 소개문 첫 3줄
6. 소식 탭: 최상단 5건 제목과 유형
7. 정보 탭: 소개문 원문, 찾아오는 길, 주차, 편의시설, SNS
8. 스타일 탭: 총 장수, 제목 예시 3개 · 사진 탭 카테고리 · 클립 유무
9. 리뷰 탭: 키워드 상위 5와 건수, 답글 예시 2개
10. 알고 있는 성과 숫자 (신규 예약/월, 객단가, 재방문율 — 없으면 '확인 필요')

## 원칙

- 기준값은 반드시 **어느 기준 매장에서 나온 값인지** 출처를 남긴다. 자료에 없는 수치는 쓰지 않는다.
- 추정치는 `~` 또는 '추정'으로 표시하고 확정치처럼 적지 않는다.
- 이미 강한 자산은 재작업이 아니라 **표준화·유지** 대상으로 분리한다.
- 공개 자료로 확인 불가한 지표(실객단가·전환율·재방문율)는 리포트에 '확인 필요 데이터'로 명기한다.
- 정책 안전선(허위 리뷰·점수 강요 금지)은 처방에서 절대 넘지 않는다.
