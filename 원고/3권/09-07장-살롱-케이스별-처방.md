## 여는 질문 — 세 명이 똑같이 "머릿결이 상했어요"라고 말할 때

고객 세 명이 같은 날 같은 말을 합니다.

**"머릿결이 너무 상한 것 같아요."**

증상은 하나인데 원인은 셋입니다. 한 명은 탈색을 반복했고, 한 명은 매일 고데기를 220도로 썼고, 한 명은 두피 유수분 균형이 무너진 상태입니다.

**여기서 세 명에게 같은 트리트먼트를 하면 어떻게 됩니까?**

한 명은 좋아지고 두 명은 그대로입니다. 그리고 두 명은 다음 달에 다른 매장으로 갑니다. 우리가 성의가 없어서가 아닙니다. **진단을 건너뛰고 처방으로 갔기 때문**입니다.

매장 문제도 똑같습니다.

"관리자가 관리를 안 해요"라는 같은 문장 뒤에, 어떤 매장은 예약이 포화라 시간이 없고, 어떤 매장은 권한이 없어서 못 하고, 어떤 매장은 애초에 유형이 안 맞습니다. **증상은 하나, 처방은 셋입니다.**

> **"9개 케이스 중 우리 매장과 가장 가까운 것은 무엇입니까? 그리고 우선 액션 1번은 무엇입니까?"**

### 3분 셀프 체크

오늘 아홉 개 케이스를 볼 텐데, 읽으면서 **'우리 얘기다' 싶은 것에 표시**해 두십시오.

해당하는 케이스 번호: ____________________

**두 개 이상 겹친다면**, 그것들은 따로 있는 문제가 아니라 **서로 연결된 하나의 구조 문제**일 가능성이 높습니다. 그 연결을 찾는 것이 오늘의 진짜 과제입니다.

지금까지는 장마다 도구 하나씩을 만들었습니다. 오늘은 **어느 도구를 꺼낼지 고르는 것 자체가 실력**입니다.

약장에 약이 다 있어도, 이 모발에 어떤 약을 쓸지 모르면 소용이 없습니다. 오늘 훈련하는 것이 그 판단입니다.

## 1. 핵심 도구 — 케이스 분해 4층법

어떤 상황이든 이 순서로 봅니다.

| 층 | 무엇을 보는가 | 확인 내용 |
| --- | --- | --- |
| **1. 상수 확인** | 위반된 상수가 있는가 | 역할 경계 · 승인 한도 · 기록 의무 등 **기존 원칙 위반부터** 확인 |
| **2. 준상수 확인** | 좌표를 잘못 읽었는가 | 규모 · 상권 · 인력 · 원장 배경의 오독 여부 점검(1권 섹션 B) |
| **3. 변수 확인** | 반복되는 변수인가 | **3회 이상 반복이면** 개인 사정이 아니라 구조 신호(2권 10장) |
| **4. 우선 액션** | 무엇을 먼저 하는가 | 상수 위반 교정 > 좌표 재측정 > 변수 대응 순 |

### 이 순서가 시술 전 확인 순서와 같습니다

시술 전에 우리가 확인하는 순서를 떠올려 보십시오.

> **① 금기 사항** — 두피 상처, 약제 알러지, 임신 여부. 여기 걸리면 시술 자체를 안 합니다.
> **② 시술 이력** — 지난번에 뭘 했는가. 흑채 썼는가, 헤나 했는가, 셀프 염색 했는가.
> **③ 오늘 상태** — 오늘 모발의 손상도와 수분감.
> **④ 시술 결정** — 그제서야 약을 고릅니다.

4층법이 정확히 이 순서입니다.

| 시술 | 매장 |
| --- | --- |
| 금기 사항 | **상수** — 여기 걸리면 다른 개선을 시작하지 않는다 |
| 시술 이력 | **준상수** — 이 매장이 원래 어떤 조건인가 |
| 오늘 상태 | **변수** — 지금 벌어지고 있는 일 |
| 시술 결정 | **우선 액션** |

**금기 확인을 건너뛰고 약을 고르는 디자이너는 없습니다.** 그런데 매장 문제에서는 그 순서를 자주 건너뜁니다. 증상이 급해 보이니까요.

### 3층의 '3회 이상'을 기억하십시오

2권 10장에서 정한 기준입니다. **같은 일이 3회 이상 반복되면 개인 사정이 아니라 구조 신호입니다.**

인턴 한 명이 갑자기 그만두면 개인 사정입니다. 같은 시기에 세 명이 그만두면 구조입니다. 예약이 한 번 꼬이면 실수고, 매주 같은 요일에 꼬이면 배치 설계 문제입니다.

케이스를 볼 때 **횟수를 먼저 세십시오.** 이 한 가지만으로 절반은 갈립니다.

## 2. 케이스 ① ~ ③ — 관리자 유형과 권한에서 생긴 문제

### 케이스 1 — 선수형 관리자가 예약 포화로 관리를 못 한다

| | |
| --- | --- |
| **증상** | "관리자를 세웠는데 하루 종일 시술만 합니다. 관리는 언제 하냐고 물으면 시간이 없대요." |
| **진단** | 선수형으로 임명했으나 **시술 시간 상한을 안 정했다.** 예약이 차면 관리 시간이 자동으로 사라진다 |
| **처방** | ① **관리 시간 30% 확보** — 예약표에 먼저 블록으로 넣는다 ② **시술 상한 설정** — 일 최대 건수 명시 ③ **고객 이관 설계** — 넘길 고객과 받을 디자이너 지정 |
| **연결** | **1권 9장** |

핵심은 순서입니다. **관리 시간을 예약표에 먼저 넣고, 남은 칸에 예약을 받습니다.** 반대로 하면 100% 실패합니다. 1권 9장에서 우리가 "교육 시간을 예약표에 먼저 넣기"라고 했던 그대로입니다.

그리고 고객 이관을 설계하지 않으면 시술 상한이 작동하지 않습니다. 상한에 걸린 고객이 갈 곳이 없으면 관리자가 결국 받습니다. **상한은 이관과 한 세트입니다.**

### 케이스 2 — 오피스형 관리자가 현장에서 인정받지 못한다

| | |
| --- | --- |
| **증상** | "관리는 잘하는데 디자이너들이 안 따릅니다. '시술도 안 하면서'라는 말이 돌아요." |
| **진단** | 오피스형의 전형적인 초기 저항. **기술 권위가 없는 상태에서 제도부터 도입**했다 |
| **처방** | ① **첫 90일 제도 유예** — 새 제도 도입을 미루고 현장 지원부터 ② **라운딩과 불편 해결** — 눈에 보이는 도움을 먼저 ③ **기술 리더 선임** — 기술 판단은 별도 리더에게 |
| **연결** | **1권 10장 · 2권 3장** |

1권 10장에서 "첫 90일은 선 트리트먼트"라고 했습니다. 상한 모발에 바로 약을 올리지 않고 전처리부터 하듯, **오피스형의 첫 90일은 제도가 아니라 신뢰 축적입니다.**

세 번째 처방이 중요합니다. 오피스형 관리자에게 기술 판단까지 맡기면 무너집니다. 2권 3장의 **이원 리더십** — 기술은 기술 리더, 운영은 운영 리더. 경계를 명시하면 "시술도 안 하면서"라는 말 자체가 성립하지 않습니다. 애초에 시술 판단을 하는 자리가 아니니까요.

### 케이스 3 — 원장의 직접 지시로 관리자가 무력화된다

| | |
| --- | --- |
| **증상** | "관리자한테 맡겼는데도 직원들이 저한테 직접 물어봐요. 저도 급하면 그냥 제가 지시하고요." |
| **진단** | **역할 경계 상수 위반.** 지시 경로가 두 개면 관리자의 지시는 참고 사항이 된다 |
| **처방** | ① **지시 경로 서약** — 원장은 팀원에게 직접 업무 지시를 하지 않는다 ② **이견은 1:1로** — 관리자 판단에 이견이 있으면 팀원 앞이 아니라 따로 ③ **승인 한도 명문화** — 관리자가 스스로 결정할 범위를 문서로 |
| **연결** | **1권 2장 · 2권 1장** |

**아홉 케이스 중 가장 흔하고, 가장 빨리 고칠 수 있는 케이스**입니다.

빨리 고칠 수 있는 이유는 원인이 명확하기 때문입니다. 제도가 부족한 게 아니라 **이미 있는 경계를 원장이 넘고 있는 것**입니다. 그래서 처방도 제도 신설이 아니라 **원장의 행동 변경**입니다.

여기서 원장님들이 자주 하시는 말이 있습니다.

> "제가 그냥 말하는 게 빠른데요."

빠릅니다. 그건 사실입니다. 다만 그 3분이 관리자의 권한을 3개월치 깎습니다. 팀원 앞에서 원장이 관리자 판단을 뒤집으면, 그 팀원은 다음부터 관리자를 건너뜁니다. 한 번만 그래도 충분합니다.

**이 케이스가 다른 케이스와 겹쳐 있을 때는 언제나 이것부터 고칩니다.** 이유는 뒤의 우선순위 규칙에서 다시 보겠습니다.

## 3. 케이스 ④ ~ ⑥ — 확장과 고객 · 인력에서 생긴 문제

### 케이스 4 — 두 지점의 문화 편차가 커진다

| | |
| --- | --- |
| **증상** | "2호점이 1호점과 너무 다릅니다. 고객이 '여기는 좀 다르네요'라고 해요." |
| **진단** | **브랜드 상수가 정의되지 않은 채 확장**했다. 무엇이 같아야 하고 무엇이 달라도 되는지 기준이 없다 |
| **처방** | ① **브랜드 상수 10개 이내로 압축** — 전 지점 동일 항목 확정 ② **지점별 운영 코드** — 상권과 인력에 맞는 현지화 블록 ③ **편차와 문화 구분** — 허용 편차인지 이탈인지 판정 기준 |
| **연결** | **1장** |

1장의 은유 그대로입니다. **시그니처 컬러는 같게, 배합은 모발에 맞게.**

세 번째 처방이 실무에서 제일 어렵습니다. 지점마다 다른 것이 전부 문제는 아닙니다. 상권이 다르면 운영이 달라야 정상입니다. **문제는 "달라도 되는 것"과 "달라서는 안 되는 것"을 구분하는 기준이 없을 때** 생깁니다.

기준이 없으면 원장은 모든 차이가 불안해집니다. 그래서 전부 통제하려 하고, 지점은 숨기기 시작합니다. 2장에서 본 **"원장님 오시는 날만 청소한다"**가 여기서 나옵니다.

### 케이스 5 — 고객수형 상권인데 객단가 전략을 쓰고 있다

| | |
| --- | --- |
| **증상** | "단가를 올렸는데 매출이 오히려 줄었습니다. 고객이 빠졌어요." |
| **진단** | **좌표 오독.** 유동 고객 중심 상권에서 객단가 전략을 쓰면 회전이 죽는다 |
| **처방** | ① **좌표 재측정** — 상권 유형을 다시 판정한다(1권 5장) ② **회전 · 밀도 우선으로 전환** — 시술 시간과 좌석 회전 설계 ③ **단계적 단가 조정** — 한 번에 올리지 않고 메뉴 단위로 |
| **연결** | **1권 5장 · 2권 6장** |

1권 5장의 원칙이 여기 걸립니다. **좋은 약은 없습니다. 이 모발에 맞는 약이 있을 뿐입니다.**

객단가 전략 자체는 훌륭합니다. 다만 **주거 밀착 · 단골 중심 상권에서 훌륭한 것**입니다. 유동 인구 중심 상권에서 같은 전략을 쓰면 고객은 옆 매장으로 갑니다. 그 상권의 고객은 관계가 아니라 접근성으로 매장을 고르니까요.

이 케이스가 무서운 이유는 **실행이 정교할수록 손실이 커진다**는 점입니다. 방향이 틀린 상태에서 열심히 하면 더 빨리 틀린 곳에 도착합니다.

### 케이스 6 — 인턴 이탈을 개인 문제로 보고 있다

| | |
| --- | --- |
| **증상** | "인턴이 계속 나갑니다. 요즘 애들이 못 버티는 것 같아요." |
| **진단** | **반복 변수를 개인 사정으로 분류**하고 있다. 3회 이상이면 구조 신호다 |
| **처방** | ① **퇴사 사유 재분류** — 지난 이탈 건을 구조 요인으로 다시 분류 ② **진도표와 데뷔 로드맵 정비** — 끝이 보이는 커리큘럼 ③ **이원 리더십 경계 정리** — 인턴에게 지시하는 사람을 정리 |
| **연결** | **2권 3 · 7장** |

**"요즘 애들은 왜 이렇게 못 버티지."**

세 권에 걸쳐 되풀이해 나온 문장입니다.

이 문장이 되풀이되는 이유가 있습니다. **이 문장은 구조 문제를 사람 문제로 오분류하는 순간의 신호**이기 때문입니다. 이 문장이 나오면 그 다음에는 항상 같은 대응이 따라옵니다. 채용을 더 하는 것. 그리고 더 뽑은 인턴도 같은 자리에서 나갑니다.

세 번째 처방을 놓치는 경우가 많습니다. 인턴 한 명에게 원장, 관리자, 선배 디자이너 세 사람이 각각 다른 기준으로 지시하면 그 인턴은 **눈치 커리큘럼**을 배웁니다. 기술이 아니라 눈치가 늘어납니다. 그리고 눈치로 버티는 자리는 오래 못 갑니다.

## 4. 케이스 ⑦ ~ ⑨ — 구조와 데이터에서 생긴 문제

### 케이스 7 — 스타 디자이너 한 명에게 매장이 종속돼 있다

| | |
| --- | --- |
| **증상** | "한 사람 매출이 매장의 절반입니다. 그 사람 눈치를 보게 됩니다." |
| **진단** | **매출 집중과 고객 개인 소유가 겹쳐 있다.** 이탈 시 고객까지 함께 나간다 |
| **처방** | ① **매출 집중도 측정** — 상위 1인 · 상위 3인 비중을 숫자로 ② **고객 이력 공유** — 개인 수첩을 공용 차트로 ③ **존 디펜스 적용** — '내 고객'을 '우리 매장 고객'으로 ④ **인정과 예외 분리** — 성과는 인정하되 규칙 예외는 주지 않는다 |
| **연결** | **1권 6장 · 2권 3 · 4장** |

네 번째 처방이 이 케이스의 핵심입니다.

원장이 흔히 하는 대응은 두 극단입니다. 예외를 다 인정하거나(그러면 매장 규칙이 무너집니다), 예외를 아예 안 주거나(그러면 그 사람이 나갑니다).

**정답은 축을 분리하는 것입니다.**

| 축 | 대응 |
| --- | --- |
| **성과 인정** | 충분히, 공개적으로, 보상으로 |
| **규칙 예외** | 주지 않는다 — 출퇴근 · 기록 · 회의 참석은 동일 |

인정을 안 주면서 규칙만 요구하면 그 사람은 억울합니다. 인정도 주고 예외도 주면 나머지 팀이 억울합니다. **인정은 최대로, 예외는 0으로**가 유일하게 지속되는 조합입니다.

그리고 두 번째 처방이 실질적 안전장치입니다. 2권 3장에서 봤듯이, 이 매장이 잃을까 봐 두려운 것은 사실 그 사람이 아니라 **그 사람 수첩에 있는 고객 이력**입니다. 이력이 공용 차트에 있으면 두려움의 크기가 절반이 됩니다.

### 케이스 8 — 대형 매장인데 밀도가 부족하다

| | |
| --- | --- |
| **증상** | "평수는 큰데 매장이 비어 보입니다. 고객이 방치되는 시간이 생깁니다." |
| **진단** | 공간 대비 **인력 배치 밀도 설계가 없다.** 넓은 매장은 저절로 관리되지 않는다 |
| **처방** | ① **구역 분할** — 매장을 구역으로 나누고 책임자를 지정 ② **라운딩 동선 설계** — 구역별 순회 주기와 확인 항목 ③ **피크 시간 배치** — 시간대별 인력 재배치 ④ **밀도 기준 설정** — 구역당 최소 상주 인원 |
| **연결** | **1권 5장 · 2권 5장** |

2권 5장의 문장이 그대로 적용됩니다. **약 올려놓고 안 보면 사고 납니다.**

40평 매장에서는 원장이 서 있는 자리에서 전체가 보입니다. 80평에서는 안 보입니다. **평수가 두 배가 되면 시야는 두 배가 되지 않고, 사각지대가 생깁니다.**

그래서 대형 매장의 라운딩은 습관이 아니라 **동선입니다.** 어느 구역을 몇 분 간격으로 어떤 항목을 보며 도는지가 정해져 있어야 합니다. "가끔 둘러본다"는 라운딩이 아닙니다.

### 케이스 9 — 숫자는 보는데 행동이 안 바뀐다

| | |
| --- | --- |
| **증상** | "매달 자료는 만드는데 달라지는 게 없습니다. 회의도 하는데요." |
| **진단** | **측정과 행동 사이의 회로가 끊겨 있다.** 지표 정의가 다르거나, 회의가 액션으로 안 끝난다 |
| **처방** | ① **KPI 정의 통일** — 지표 정의서로 같은 말이 같은 뜻이 되게 ② **3단 회로 가동** — 측정 → 해석 → 액션의 회의 구조 ③ **액션 이행률 관리** — 지난 회의 액션의 완료 여부를 첫 안건으로 |
| **연결** | **2권 8 · 9장** |

2권 8장의 질문이 여기 걸립니다. **우리가 말하는 7레벨이 같은 7레벨입니까?**

재방문율을 세 사람이 각각 다르게 계산하고 있으면, 회의에서 아무리 오래 이야기해도 결론이 안 납니다. 각자 다른 숫자를 보고 있으니까요.

세 번째 처방이 가장 빠른 효과를 냅니다. **지난 회의 액션의 이행 여부를 이번 회의 첫 안건으로 올리는 것**. 이것만 해도 액션 이행률이 눈에 띄게 올라갑니다. 이유는 단순합니다. 다음 회의에서 확인받는다는 걸 알면 사람은 합니다.

2권 9장에서 우리는 회의를 시술에 비유했습니다. **시술은 차트 확인으로 시작합니다.** 지난번에 뭘 했는지 안 보고 오늘 약을 고르는 디자이너는 없습니다.

## 5. STEP 1 · 상수 — 처방 4원칙

여기서부터는 원칙입니다.

### 상수 1 — 처방 전에 진단한다. 케이스가 비슷해 보여도 좌표가 다르면 처방이 다르다.

증상의 유사성으로 처방을 결정하지 않는다. 좌표를 먼저 확인한다.

### 상수 2 — 상수 위반부터 교정한다. 원칙이 깨진 상태에서는 어떤 개선도 작동하지 않는다.

역할 경계 · 승인 한도 · 기록 의무의 위반은 다른 모든 개선에 앞선다.

### 상수 3 — 우선 액션은 1개로 시작한다. 한 번에 여러 개를 바꾸면 무엇이 효과였는지 모른다.

동시 시행은 검증을 불가능하게 만든다. 하나를 바꾸고 결과를 본 뒤 다음으로 간다.

### 상수 4 — 처방 후 결과를 기록한다. 효과가 없으면 처방이 아니라 진단을 다시 본다.

효과 없는 처방을 강화하지 않는다. 진단으로 돌아간다.

### 상수 3에 대한 보충

세 번째 상수가 실무에서 가장 지키기 어렵습니다.

문제가 세 개 보이면 세 개를 다 고치고 싶어집니다. 급하니까요. 그런데 세 개를 동시에 바꾸고 두 달 뒤 상황이 좋아지면, **무엇 때문에 좋아졌는지 알 수 없습니다.** 나빠져도 마찬가지입니다.

2권 8장에서 매출이 안 나올 때 약 · 시간 · 모발 중 무엇이 원인인지 특정하라고 했습니다. 셋 다 동시에 바꾸면 특정이 안 됩니다.

그리고 실무적으로 더 중요한 이유가 있습니다. **동시 시행은 팀을 지치게 합니다.** 한 달에 새 제도 세 개가 들어오면 팀은 셋 다 대충 합니다. 하나가 자리를 잡은 뒤 다음을 넣으면 셋 다 삽니다.

### 상수 4에 대한 보충

효과가 없을 때 우리가 흔히 하는 대응은 **강화**입니다. 회의를 늘리고, 점검을 늘리고, 압박을 늘립니다.

그런데 처방이 안 듣는 이유는 대개 처방이 약해서가 아니라 **진단이 틀려서**입니다. 손상 원인이 열기구인데 단백질 트리트먼트를 계속 강화하면, 모발은 오히려 뻣뻣해집니다.

기록이 필요한 이유가 여기 있습니다. 무엇을 언제 시행했고 얼마 뒤 무엇이 달라졌는지가 남아 있어야, **진단을 다시 볼 근거**가 생깁니다.

## 6. STEP 2 · 변수 — 우리 매장 케이스 진단

여섯 개 질문으로 오늘 우리 매장을 판별합니다.

| 항목 | 질문 | 판정 |
| --- | --- | --- |
| **해당 케이스** | 9개 중 우리에게 해당하는 것은? | 2개 이상 = **연결 구조** |
| **상수 위반** | 위반된 상수가 있는가? | 있음 = **최우선 교정** |
| **좌표 오독** | 좌표를 잘못 읽고 있는가? | 있음 = **재측정 우선** |
| **반복 변수** | 3회 이상 반복된 변수가 있는가? | 있음 = **상수 개정** |
| **도구 보유** | 필요한 도구를 이미 만들었는가? | 없음 = **해당 장 복습** |
| **우선 액션** | 첫 번째로 할 일을 1개로 좁혔는가? | 여러 개 = **검증 불가** |

### 첫 번째 항목의 '2개 이상 = 연결 구조'

이것이 이 장에서 가장 중요한 판정입니다.

케이스가 두 개 이상 해당한다는 것은 문제가 두 개라는 뜻이 아닙니다. **대개는 하나의 원인이 두 곳에서 증상으로 나타나는 것**입니다.

예를 들어 케이스 3(원장 직접 지시)과 케이스 6(인턴 이탈)이 같이 있는 매장은 흔합니다. 우연이 아닙니다. 지시 경로가 두 개면 인턴이 가장 먼저 혼란스러워지고, 혼란스러운 인턴이 먼저 나갑니다. **케이스 3을 고치면 케이스 6이 같이 줄어듭니다.**

겹치는 케이스를 발견하면, 각각을 따로 고치기 전에 **연결을 먼저 찾으십시오.** 뒤의 사례가 정확히 이 이야기입니다.

### 네 번째 항목 — '3회 이상 = 상수 개정'

2권 10장에서 정한 규칙입니다. 같은 변수가 세 번 반복되면 그건 변수가 아니라 **아직 상수로 만들지 않은 규칙**입니다.

노쇼가 세 번 반복되면 노쇼 대응을 상수로 만들고, 마감 누락이 세 번 반복되면 마감 확인을 상수로 만듭니다. 매번 개별 대응하는 것은 같은 일을 무한히 반복하겠다는 뜻입니다.

## 7. STEP 3 · 결정 규칙 — 복수 케이스가 겹칠 때

케이스가 여러 개일 때는 **순서가 처방입니다.**

| 순위 | 대상 | 이유 |
| --- | --- | --- |
| **1순위** | **안전 · 법 · 금전 리스크** | 즉시 처리 — 다른 어떤 개선보다 앞선다(2권 4장 즉시 이관) |
| **2순위** | **상수 위반** (권한 · 경계 · 기록) | 구조의 기반이므로 먼저 교정 — **케이스 3이 대표적** |
| **3순위** | **좌표 오독** (전략 방향) | 방향이 틀리면 실행이 정교해도 손실 — **케이스 5가 대표적** |
| **4순위** | **시스템 · 인력 개선** | 위 셋이 정리된 뒤 착수 — 그래야 효과가 유지된다 |

### 1순위는 판단하지 않습니다

안전 · 법 · 금전 리스크는 우선순위를 따지는 대상이 아닙니다. **발견 즉시 처리하고, 즉시 원장에게 올립니다.**

2권 4장에서 정한 즉시 이관 항목이 그대로 여기 옵니다. 약제 사고, 고객 안전, 임금 · 근로 관련, 금전 사고, 성희롱 · 괴롭힘. 이 항목들은 관리자가 판단하는 자리가 아니라 **올리는 자리**입니다.

### 4순위가 왜 마지막인가

시스템과 인력 개선은 가장 눈에 띄고 가장 하고 싶은 일입니다. 새 제도, 새 교육, 새 채용. 뭔가 하고 있다는 느낌이 듭니다.

그런데 이것을 먼저 하면 **효과가 유지되지 않습니다.**

권한 경계가 깨진 상태에서 새 교육 프로그램을 도입하면, 교육받은 사람이 배운 대로 행동하려다 원장의 직접 지시와 충돌합니다. 좌표를 잘못 읽은 상태에서 인력을 늘리면, 틀린 방향으로 더 많은 인력이 갑니다.

**1~3순위는 기반이고 4순위는 그 위에 얹는 것입니다.** 기반 없이 얹으면 무너집니다.

## 8. STEP 4 · 현장 사례 — 케이스 세 개가 얽혀 있던 매장

### 상황

70평 18인 매장이었습니다. 세 가지 문제가 동시에 있었습니다.

| 문제 | 케이스 |
| --- | --- |
| 관리자가 예약 포화로 관리 시간이 없음 | **케이스 1** |
| 원장이 팀원에게 직접 지시 | **케이스 3** |
| 인턴 이탈이 반복 | **케이스 6** |

원장은 세 문제를 **동시에** 해결하려 했습니다.

> ① 관리자를 교체했습니다.
> ② 교육 프로그램을 도입했습니다.
> ③ 인턴 채용을 확대했습니다.

여섯 달 뒤, 상황은 더 나빠졌습니다.

### 매트릭스 재해석

| 관점 | 진단 |
| --- | --- |
| **순서 오류** | 우선순위 없이 동시 시행 — **무엇이 효과였는지 검증 불가**, 상수 3 위반 |
| **바른 순서** | ① 케이스 3(상수 위반: 지시 경로) → ② 케이스 1(관리 시간 확보) → ③ 케이스 6(인턴 구조) |
| **이유** | 지시 경로가 안 잡히면 관리자가 시간을 확보해도 권한이 없고, 권한이 없으면 인턴 구조도 못 바꾼다 |

### 세 가지 대응이 각각 왜 실패했는가

**① 관리자 교체** — 새 관리자도 같은 자리에 앉았습니다. 지시 경로가 그대로였으니, 새 사람도 똑같이 무력화됐습니다. 사람이 문제가 아니었다는 증거가 하나 더 쌓였을 뿐입니다.

**② 교육 프로그램 도입** — 인턴들은 교육에서 배운 절차와 현장에서 받는 지시가 다르다는 것을 배웠습니다. 교육이 오히려 혼란을 키웠습니다.

**③ 인턴 채용 확대** — 나가는 구조를 그대로 두고 들어오는 인원을 늘렸습니다. **구멍 난 양동이에 물을 더 부은 것**입니다. 2권 6장에서 유입만 늘리는 것을 그렇게 불렀습니다.

세 대응 모두 성의는 충분했습니다. **순서가 없었을 뿐입니다.**

### 바른 순서가 왜 그 순서인가

이 사례에서 가장 배울 것은 순서의 논리입니다.

> **지시 경로가 안 잡히면** → 관리자가 시간을 확보해도 그 시간에 내린 결정이 뒤집힙니다.
> **권한이 없으면** → 인턴 교육 체계를 만들어도 시행할 힘이 없습니다.

그래서 케이스 3이 먼저입니다. 그리고 케이스 3의 처방은 **가장 싸기도 합니다.** 원장이 직접 지시를 멈추고, 이견은 1:1로 말하고, 승인 한도를 문서로 정하는 것. 돈이 안 듭니다. 채용도 필요 없습니다.

**여섯 달 동안 관리자 교체와 프로그램 도입과 채용 확대에 들어간 비용보다, 원장의 행동 하나를 바꾸는 것이 효과가 컸습니다.**

이 문장이 불편하실 수 있습니다. 그런데 이 불편함이야말로 2순위 상수 위반이 왜 그렇게 오래 방치되는지를 설명합니다. **다른 처방은 남을 바꾸는 일이고, 이 처방은 나를 바꾸는 일이기 때문입니다.**

4장에서 후보를 점수가 아니라 사례로 기록하라고 했던 것과 같습니다.

```
위반 상수: ____________________

                    ____________________
                    ____________________
```

## 10. 워크숍 — 우리 매장 케이스 처방

### 공동 실습 버전 (20분)

| 단계 | 내용 | 시간 |
| --- | --- | --- |
| **1. 판별** | 9개 케이스 중 해당하는 것을 모두 표시한다 | 3분 |
| **2. 분해** | 각 케이스를 4층법(상수 · 준상수 · 변수 · 액션)으로 분해한다 | 7분 |
| **3. 순서** | 우선순위 규칙으로 처방 순서를 정한다 | 5분 |
| **4. 발표** | 우선 액션 1개 발표 — **왜 그것이 첫 번째인지** 근거를 말한다 | 5분 |

### 4단계의 채점 기준

발표에서 확인할 것은 액션의 내용이 아니라 **근거**입니다.

| 약한 근거 | 강한 근거 |
| --- | --- |
| "이게 제일 급해 보여서요" | "케이스 3이 상수 위반이고, 2순위 규칙상 케이스 1보다 앞섭니다" |
| "이것부터 하면 될 것 같아서" | "케이스 3을 고치면 케이스 6이 같이 줄어드는 연결이 있습니다" |

오른쪽처럼 말할 수 있으면 이 과정을 제대로 통과한 겁니다. **규칙을 근거로 순서를 설명할 수 있다는 것**이 이 책 전체의 목표였습니다.

### 혼자 읽는 독자를 위한 버전

**1단계 — 표시 (3분)**

⑥번 시트의 체크리스트에 표시합니다. 솔직하게 하십시오. 아무도 안 봅니다.

**2단계 — 연결 찾기 (5분)**

2개 이상 표시했다면, 이 질문에 답해 보십시오.

> **"이 케이스들 중 하나를 고치면 다른 것이 같이 줄어드는 게 있습니까?"**

자주 나오는 연결을 몇 개 적어 둡니다.

| 연결 | 관계 |
| --- | --- |
| **3 → 6** | 지시 경로가 정리되면 인턴 혼란이 줄어든다 |
| **3 → 1** | 권한이 서면 관리자가 시술 요청을 거절할 수 있다 |
| **1 → 8** | 관리 시간이 생겨야 라운딩과 밀도 관리가 가능하다 |
| **9 → 4** | 지표 정의가 통일돼야 지점 편차를 판정할 수 있다 |
| **7 → 6** | 스타 종속이 풀려야 인턴 교육에 자원이 간다 |

**3단계 — 순서 정하기 (5분)**

우선순위 규칙 4단계를 그대로 적용합니다. 안전 · 법 · 금전 → 상수 위반 → 좌표 오독 → 시스템 · 인력.

여기서 자주 나오는 함정이 있습니다. **가장 아픈 문제를 1순위로 놓고 싶어집니다.** 아픈 것과 먼저 할 것은 다릅니다. 인턴이 계속 나가는 게 제일 아프더라도, 지시 경로가 깨져 있으면 그것부터입니다.

**4단계 — 액션 하나 쓰기 (5분)**

⑥번 칸을 채웁니다. 담당 · 기한 · 완료 기준 · 결과 확인일까지 전부요.

그리고 이 칸을 **다음 장에 가져오십시오.** 8장에서 90일 로드맵을 만들 때, 이 액션이 첫 번째 칸에 들어갑니다.

> **1. 케이스가 비슷해도 좌표가 다르면 처방이 다릅니다.**
> 진단이 먼저입니다. 같은 "머릿결이 상했어요"에 같은 트리트먼트를 하면 두 명은 그대로입니다.
>
> **2. 상수 위반부터 교정합니다.**

>
> **3. 우선 액션은 1개입니다.**
> 한 번에 여러 개를 바꾸면 무엇이 효과였는지 알 수 없습니다. 하나를 바꾸고, 결과를 보고, 다음으로 갑니다.
