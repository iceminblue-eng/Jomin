# 입구 · 이 권부터 읽는 분께

> **관리자론 3 — 확장과 양성**

---

앞의 두 권을 안 읽으셨어도 이 권은 시작할 수 있습니다.

2호점 문제가 눈앞에 있거나, 관리자 후임이 급하시다면 여기서 출발하는 게 맞습니다. 필요한 **최소 도구 다섯 가지**를 여기서 드리겠습니다.

---

## 1. 3층 개념과 운영 코드

이 시리즈는 매장의 모든 일을 세 층으로 나눕니다.

| 층 | 무엇인가 | 다루는 법 |
| --- | --- | --- |
| **상수** | 어떤 상황에서도 지키는 기준 | **지킨다** |
| **준상수** | 쉽게 바뀌지 않는 조건 — 평수 · 상권 · 인원 · 원장 배경 | **분기마다 잰다** |
| **변수** | 오늘 발생하는 상황 — 노쇼 · 결원 · 클레임 | **대응하고 기록한다** |

**이 권에서 이 구분이 왜 필요한가.** 지점마다 달라진 것이 *지켜야 할 기준의 차이*인지 *조건에 맞게 달라져야 할 실행 방식의 차이*인지를 갈라야 하기 때문입니다.

지점이 여럿이면 **지점마다** 코드를 적으십시오.

```
[ 지점별 운영 코드 ]

지점 ______  실평수 ___평 / 상권 ___급 / 총원 ___명 / ☐고객수형 ☐객단가형
지점 ______  실평수 ___평 / 상권 ___급 / 총원 ___명 / ☐고객수형 ☐객단가형
지점 ______  실평수 ___평 / 상권 ___급 / 총원 ___명 / ☐고객수형 ☐객단가형
```

## 2. 관리자 유형 요약표

후보를 볼 때와 지점의 요구를 대조할 때 씁니다.

| 유형 | 성과를 내는 방식 | 전제 조건 |
| --- | --- | --- |
| **선수형** | 기술과 현장 성과로 신뢰를 얻는다 | 관리 시간 선확보 · 시술 상한 |
| **오피스형** | 데이터 · 인사 · 제도로 성과를 만든다 | **기술 리더의 존재** · 현장 신뢰 |
| **복수형** | 둘 이상이 영역을 나눈다 | 결정 영역 구분과 조율 절차 |
| **혼합형** | 한 사람이 두 역할을 한다 | 시간 비율 고정과 측정 |

## 3. 역할 · 권한 기본표

**양성이 권한 없는 과제가 되지 않도록** 이것부터 채우십시오.

```
[ 최소 권한표 ]

관리자 단독 결정 금액: 건당 ________원 / 월 ________원
지시 경로: 원장은 팀원에게 직접 업무 지시를 하지 않는다   ☐ 합의  ☐ 미합의
보고 주기: ____________________
즉시 이관 항목 (판단하지 않고 바로 올릴 일)
  ☐ 안전 · 약제 사고   ☐ 법 · 근로 관련   ☐ 금전 사고   ☐ 괴롭힘 · 인권
```

후보에게 프로젝트를 맡기실 때도 **그 프로젝트의 권한 범위**를 같이 정해야 합니다. 권한 없이 과제만 주면 후보는 배우는 게 아니라 시달립니다.

## 4. 4축 KPI와 지표 정의

평가 · 보상 · 지점 비교의 기준을 맞추는 데 씁니다.

| 축 | 항목 | 우리 지표 |
| --- | --- | --- |
| **고객** | 재방문 · 클레임 해결 | ____________________ |
| **선수** | 팀 유지 · 교육 이수 | ____________________ |
| **환경** | 운영 안정 · 재고 적정 | ____________________ |
| **데이터** | 보고 정시 · 액션 이행 | ____________________ |

> **정의 예시** — "재방문율 = 당월 신규 고객 중 90일 이내에 2회 방문을 완료한 고객의 비율. 분모는 당월 첫 방문 고객, 분자는 그중 90일 내 재방문자. 매월 익월 말 산출."

**지점을 비교하시려면 이 정의부터 통일해야 합니다.** 정의가 다르면 비교가 아니라 오해가 됩니다.

## 6. 운영 성숙도 — 지금 어디에 계신지

이 권을 읽는 목적이 단계마다 다릅니다. 먼저 위치를 잡으십시오.

| 단계 | 상태 | 이 권에서 볼 곳 |
| --- | --- | --- |
| **1단계 · 원장 의존** | 모든 결정이 원장을 거친다 | 1 · 2권을 먼저 권합니다 |
| **2단계 · 관리자 운영** | 권한 한도와 역할 경계가 문서로 있다 | **4~6장(양성)**부터 |
| **3단계 · 시스템 운영** | 사람이 바뀌어도 유지된다 | **1~3장(다지점)** 포함 전체 |
| **4단계 · 다점포 복제** | 재현 가능한 모델로 확장한다 | 전체 + 총괄 육성 |

**상세한 판정 기준과 관문은 마지막 장에 있습니다.** 여기서는 대략의 위치만 잡고 가십시오.

## 읽는 경로

**지점이 하나라면** — 리캡 · 최소 도구 → **4~6장(선발 · 양성 · 성장)** → 7장(케이스 처방) → 8장(90일 로드맵). 앞의 세 장(다지점)은 승계와 향후 확장을 검토하실 때 연결하시면 됩니다. **지금 총괄 조직을 만들어야 한다는 뜻이 아닙니다.**

**지점이 둘 이상이라면** — 리캡 · 지점별 운영 코드 → **1~3장(표준화 · 거버넌스 · 비교 학습)** → 4~6장(양성) → 7장 → 8장.

그럼 시작하겠습니다.
