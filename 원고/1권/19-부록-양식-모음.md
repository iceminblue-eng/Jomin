# 부록 · 양식 모음

> **관리자론 1 — 기준과 진단 · 네 개의 빈 양식**

---

본문에서 만든 도구의 **빈 양식**입니다. 복사해서 쓰시라고 뒤에 모았습니다.

| 부록 | 양식 | 완성 지점 | 다음 권과의 연결 |
| --- | --- | --- | --- |
| **1** | 원장 · 관리자 역할 헌장 | 2장 | 2권 부록 1 권한 위임표로 확장 |
| **2** | 관리자 성과 스코어카드 | 3장 | 2권 부록 5 KPI 정의서로 정밀화 |
| **3** | 진단 인테이크 시트 | 8장 | 1권 12장 유형 점수표의 입력값 |
| **4** | 관리자 유형 선택 점수표 | 12장 | 권말 실습 모델 결정서로 통합 |

**한 번에 다 채우지 마십시오.** 해당 장을 읽으신 뒤 그 장의 양식만 채우시면 됩니다.

---

## 부록 1 · 원장 · 관리자 역할 헌장

> **완성 지점** 2장 · **서명이 이 문서를 합의로 만듭니다**

```
[ 역할 헌장 ]                          작성일 ______년 ___월 ___일

① 관리자 미션 — 이 매장에서 관리자가 존재하는 이유 (한 문장, 결과로)
   ____________________________________________________________

② 결정 권한 목록 — 스스로 결정하는 업무와 비용 승인 한도
   1. ________________________________  한도 ________원
   2. ________________________________  한도 ________원
   3. ________________________________  한도 ________원
   4. ________________________________  한도 ________원
   5. ________________________________  한도 ________원
   ※ 금액은 임시라도 반드시 숫자로 적습니다

③ 보고 의무 목록 — 사전 승인이 필요한 사안과 보고 기한
   1. ____________________________  기한 ☐ 즉시  ☐ 당일  ☐ 주간
   2. ____________________________  기한 ☐ 즉시  ☐ 당일  ☐ 주간
   3. ____________________________  기한 ☐ 즉시  ☐ 당일  ☐ 주간
   4. ____________________________  기한 ☐ 즉시  ☐ 당일  ☐ 주간
   5. ____________________________  기한 ☐ 즉시  ☐ 당일  ☐ 주간

④ 지시 경로 서약
   ☐ 원장은 팀원에게 직접 업무 지시를 하지 않는다
   ☐ 관리자 판단에 이견이 있으면 팀원 앞이 아니라 1:1로 말한다
   긴급 예외 (안전 · 위생): ____________________________________
     → 예외 시행 후 관리자에게 공유하는 방법: ____________________

⑤ 예외 처리 절차 — 제안 → 승인 → 기록 → 환류
   제안 경로: ____________________   승인자: ____________________
   기록처 (물리적으로 지정): ____________________________________
   환류 주기: ☐ 월 1회  ☐ 분기 1회      담당: ____________

⑥ 서명
   원장 ______________   관리자 ______________   일자 ___/___/___
   분기 재검토 예정일: ______년 ___월 ___일
```

**⑤번의 기록처를 '노션'처럼 도구 이름으로만 적지 마십시오.** 어느 페이지, 어느 시트인지까지 적어야 다음 사람이 찾습니다.

## 부록 2 · 관리자 성과 스코어카드

> **완성 지점** 3장 · **지표는 6~8개가 실무 상한선입니다**

```
[ 관리자 성과 스코어카드 ]              적용 분기 ______년 ___분기

① 고객 축 (2~3지표)   — 좌표에 맞게 선택
   ____________________  현재 ______ → 목표 ______
   ____________________  현재 ______ → 목표 ______
   ____________________  현재 ______ → 목표 ______

② 선수 축 (2~3지표)   — 인턴 비중 높으면 온보딩·교육 우선
   ____________________  현재 ______ → 목표 ______
   ____________________  현재 ______ → 목표 ______

③ 환경 축 (1~2지표)   — 평수가 클수록 피크·동선 우선
   ____________________  현재 ______ → 목표 ______

④ 데이터 축 (1~2지표) — 처음이면 보고 정시율부터
   ____________________  현재 ______ → 목표 ______

⑤ 개인 매출 (상한제)
   우리 관리자 유형: ☐ 선수형  ☐ 오피스형  ☐ 복수형  ☐ 혼합형
   적용 상한: ______%     (선수형 최대 30 / 오피스형 0)

⑥ 부재 품질 (분기 1회) — 최종 지표
   관리자 부재일 점검 결과: ____________________
   측정일: ___/___      담당: ____________

지표 총 개수: ______개   (6~8개 권장)
```

**⑥번을 빼지 마십시오.** 앞의 다섯 축이 다 좋아도 부재일에 무너지면 그건 관리자의 성과가 아니라 관리자의 출근입니다.

## 부록 3 · 진단 인테이크 시트

> **완성 지점** 8장 · **지점이 둘 이상이면 지점 수만큼 복사합니다**

```
[ 진단 인테이크 ]        지점명 ____________   작성일 ___/___/___

① 6대 질문 — 숫자와 근거로
   Q1 규모      실평수 ______평 / 좌석 ______석
   Q2 상권      ☐ A급  ☐ B급  ☐ C급    근거: ____________________
   Q3 조직      디자이너 ___명 / 인턴 ___명 / 데스크 ___명 / 총 ___명
                실질 부하 점수 ______
   Q4 비즈니스  ☐ 고객수형  ☐ 객단가형   근거: ____________________
   Q5 원장      ☐ 미용인  ☐ 비미용인   창업 ______년차
                원장의 사각지대: ____________________
   Q6 지점      ______개

② 운영 코드 한 줄
   ____________________________________________________________
   (규모 · 상권 · 부하N · 유형 · 배경연차)

③ 출력 3종
   관리자 유형(가설): ____________________   ※ 12장에서 확정
   권한 단계(가설):   ☐ L1  ☐ L2  ☐ L3
   KPI 방향:          ____________________

④ 우선 과제 3 — 세 개를 넘기지 마십시오
   1. ____________________________________
   2. ____________________________________
   3. ____________________________________

⑤ 재측정 일정
   다음 재측정일: ______년 ___월 ___일      담당: ____________

⑥ 지점별 코드 (2개 지점 이상)
   지점 ______ : ____________________________________
   지점 ______ : ____________________________________
   지점 ______ : ____________________________________
```

**③번의 유형은 가설입니다.** 여기서 확정하지 마십시오. 12장 점수표로 검증한 뒤에 확정합니다.

## 부록 4 · 관리자 유형 선택 점수표

> **완성 지점** 12장 · **8장 운영 코드에서 대부분의 숫자가 나옵니다**

```
[ 관리자 유형 선택 점수표 ]             작성일 ______년 ___월 ___일

① 점수 산출
   현장 복잡도                        시스템 복잡도
   실질 부하    ______점              평수 규모     ______점
   인턴 비중    ______점              지점 수       ______점
   원장 배경    ______점              데이터 요구   ______점
   ─────────────                    ─────────────
   현장 합계    ______점              시스템 합계   ______점

② 사분면 배치
   우리 사분면: ☐ Q1  ☐ Q2  ☐ Q3  ☐ Q4
   권장 모델:   ____________________
   그 칸의 조건: ____________________________________

③ 가설 대조
   8장 가설:     ____________________
   12장 확정안:  ____________________
   바뀌었다면 사유: ____________________________________

④ 경제성
   운영 손실 추정액 (월): ________원
   관리자 인건비 증분 (월): ________원
   결론: ☐ 도입  ☐ 보류  ☐ 형태 변경     근거: ______________

⑤ 90일 계획
   0~30일  검증 항목: ____________________  판정 기준: __________
   31~60일 검증 항목: ____________________  판정 기준: __________
   61~90일 검증 항목: ____________________  판정 기준: __________
   판정일: ______년 ___월 ___일

⑥ 조기 신호 — 선택이 틀렸음을 알리는 신호
   1. ____________________________________
   2. ____________________________________
   3. ____________________________________
   점검 주기: 월 1회 (매월 ______일)   담당: ____________
```

**④번의 자릿수만 맞으면 충분합니다.** 정확한 회계가 목적이 아니라, 관리자 인건비가 손실보다 싼지를 보는 것이 목적입니다.

## 이 네 장을 어디에 두는가

| 양식 | 두는 곳 |
| --- | --- |
| **부록 1 역할 헌장** | 원장과 관리자가 각각 한 부씩. 회의 자료 고정 페이지에도 |
| **부록 2 스코어카드** | 분기 평가 면담 자리에 |
| **부록 3 인테이크** | 분기 재측정일에 다시 꺼낼 수 있는 곳 |
| **부록 4 점수표** | 권말 실습 「관리자 모델 결정서」에 붙여서 보관 |

**네 장이 한 파일에 모여 있어야 합니다.** 흩어지면 2권을 시작할 때 다시 만들게 됩니다.
