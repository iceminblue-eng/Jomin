> **제2부 — 상수와 변수로 우리 살롱의 좌표를 찾아라 · 2부 개막**
> **적용 범위** 중대형 살롱(40평 이상 · 8인 이상) · 다점포(2개 지점 이상)

### 이 장의 좌표

| 항목 | 내용 |
| --- | --- |
| **이 장의 질문** | 지난달 만든 새 규정 중, 사실은 기존 상수로 해결됐어야 할 것은 무엇인가? |

| **이 장의 도구** | 3층 분류표 — 우리 매장 규칙 전수 분류 시트 |
| **매트릭스 대입 포인트** | **매트릭스 문법 학습** — 세 층위의 구분 기준 자체를 훈련한다 |

## 제2부 로드맵 — 4장에서 8장까지

1부에서 매트릭스의 뼈대를 봤습니다. 2부에서는 그 안에 넣을 **입력값**을 완성합니다.

| 장 | 무엇을 하는가 |
| --- | --- |
| **4장** | **문법** — 상수 · 준상수 · 변수, 세 층위의 구분 기준을 훈련한다 *(오늘)* |
| **5장** | **구조 좌표** — 평수 · 상권 등급 · 지점 수, 물리적 조건값을 읽는다 |
| **6장** | **조직 좌표** — 인원수 · 구성 조합 · 인턴 제도, 팀의 조건값을 읽는다 |
| **7장** | **사람 좌표** — 원장 배경 · 연차 · 세대, 사람의 조건값을 읽는다 |
| **8장** | **인테이크** — 세 좌표를 진단 질문으로 통합해 '운영 코드'를 만든다 |

오늘이 4장, 문법 시간입니다. 좌표를 읽기 전에 **좌표를 읽는 법**을 배웁니다.

## 여는 질문 — 지난 3개월에 규칙이 몇 개 늘었습니까

3장 과제로 관리자의 일주일 시간 사용을 4축으로 분류해 보셨을 겁니다. 평가표와 실제 시간이 안 맞았을 것이고요. 그 불일치가 오늘의 출발점입니다.

관리자의 시간이 어디로 샜는지 보면, 대개 한 덩어리가 보입니다. **"이번엔 이렇게 하기로 했습니다" 공지 만들고 알리고 확인하는 시간.**

그래서 오늘의 질문은 이겁니다.

> **"지난달 만든 새 규정 중, 사실은 기존 상수로 해결됐어야 할 것은 무엇입니까?"**

### 3분 셀프 체크

1. **최근 3개월 사이에 우리 매장에 새로 생긴 규칙 · 공지 · 지침을 모두 적으십시오. 몇 개입니까?**

   ▸ ______개

2. **그중 '기존 원칙을 다시 알려주는 것만으로 해결됐을 것'에 표시해 보십시오.**

   ▸ ______개

세어 보시면 대개 본인도 놀랍니다. 3개월에 예닐곱 개는 우습게 나옵니다. 그리고 그중 절반은 새 규칙이 아니라 **이미 있는 원칙을 다시 말한 것**입니다.

문제는 그게 '다시 말한 것'으로 인식되지 않고 **새 규칙으로 쌓인다**는 데 있습니다.

## 이 장이 끝나면 할 수 있어야 하는 것

**1. 3층 정의** — 상수·준상수·변수를 실무 언어로 정의하고 예를 든다.
**2. 층위 판별** — 어떤 규칙·문제든 판별 질문 3개로 층위를 배정한다.
**3. 규정 다이어트** — 우리 매장 규칙을 전수 분류해 상수를 굵게, 규정을 얇게 만든다.

### 매트릭스 대입 — 문법 학습

1부에서 매트릭스의 뼈대를 봤다면, 오늘은 **그 뼈대를 움직이는 문법**을 배웁니다.

이 문법이 손에 익으면 놀라운 일이 생깁니다. **5~8장의 좌표 진단, 22장의 변수 대응, 29장의 케이스 처방이 전부 같은 동작의 반복**이라는 걸 알게 됩니다.

이 책이 두꺼워 보이는 건 내용이 많아서가 아닙니다. 같은 동작을 여러 상황에 적용하기 때문입니다. 오늘 그 동작 하나를 배웁니다.

## 1. 도입 — 문제마다 규정을 만들면 생기는 일

문제가 생겼습니다. 원장은 공지를 붙입니다. 합리적입니다. 다시는 그 문제가 안 생기게 하려는 거니까요.

그런데 이 합리적인 행동을 3년 반복하면 매장이 이렇게 됩니다.

### 함정 1 — 규정 인플레

**문제 1건 = 규정 1개.** 1년이면 수십 개가 됩니다.

그리고 어느 순간, 그 규정집을 전부 아는 사람이 매장에 한 명도 없게 됩니다. **만든 원장님을 포함해서요.**

### 함정 2 — 규정 충돌

따로따로 만든 규정끼리 모순됩니다.

작년 3월 공지에는 "노쇼 고객은 다음 예약 시 선입금"이라고 되어 있고, 올해 1월 공지에는 "단골 고객 편의를 최우선으로"라고 되어 있습니다. 둘 다 맞는 말이고, 둘 다 붙어 있습니다.

그러면 팀원은 어떻게 합니까? **상황마다 유리한 규정을 골라 씁니다.** 변호사처럼요. 그리고 그건 팀원 탓이 아닙니다. 우리가 그렇게 하도록 만들어 놓은 겁니다.

### 함정 3 — 교육 불능

신입에게 가르칠 수 없는 분량이 됩니다.

74개짜리 규정집을 신입에게 주면서 "일주일 안에 숙지하세요"라고 할 수는 없습니다. 그래서 결국 이렇게 됩니다. **"모르면 선배한테 물어봐."**

1장의 **눈치 커리큘럼**이 74건짜리 규정집을 뚫고 부활하는 순간입니다. 규정을 그렇게 많이 만든 이유가 바로 그 눈치 커리큘럼을 없애기 위해서였는데 말입니다.

### 함정 4 — 원칙 실종

가장 조용하고 가장 치명적입니다.

규정은 많은데 **'왜'가 사라집니다.** 규정은 결론만 담고 있지 판단 기준을 담고 있지 않기 때문입니다.

그래서 새로운 상황이 오면 아무도 판단하지 못합니다. 그리고 어떻게 합니까? **또 규정을 만듭니다.** 이렇게 고리가 닫힙니다.

## 2. 빅 픽처 — 매트릭스 한 장 요약

여기서 이 책 전체의 지도를 한 번 펼치겠습니다. 좌표를 넣으면 운영이 나오는 장치, 그 전체 모습입니다.

```
┌─ 입력 · 좌표 ────────┐   ┌─ 처리 · 3층 문법 ───┐   ┌─ 출력 · 운영 설계 ──────┐
│                      │   │                      │   │                        │
│  구조 좌표 (5장)     │   │  상수                │   │  관리자 유형 (3부)     │
│  평수 · 상권 · 지점수 │   │  어떤 좌표에서도     │   │  선수형·오피스형·혼합  │
│                      │→ │  불변                │→ │                        │
│  조직 좌표 (6장)     │   │                      │   │  권한 · 역할 헌장 (4부)│
│  인원 · 구성 · 인턴제 │   │  준상수              │   │  승인 한도 · 보고선    │
│                      │   │  좌표가 정하는 조건값 │   │                        │
│  사람 좌표 (7장)     │   │                      │   │  KPI 스코어카드 (3장)  │
│  원장 배경·연차·세대  │   │  변수                │   │  4축 + 부재 품질       │
│                      │   │  매일 흔들리는 상황값 │   │                        │
└──────────────────────┘   └──────────────────────┘   └────────────────────────┘
        ▲                                                            │
        └──── 환류: 반복되는 변수는 상수 개정으로 되돌아온다 (22장) ──┘
```

지금까지 배운 것들이 이 그림 어디에 있는지 확인해 보십시오.

- 2장의 **역할 경계** → 처리 칸의 '상수' 첫 줄
- 3장의 **KPI 스코어카드** → 출력 칸의 세 번째 상자
- 1장의 **원장 부재 72시간 테스트** → 입력을 측정하는 도구

그리고 아래쪽 **환류 화살표**를 보십시오. 이게 이 매트릭스를 살아 있게 만드는 선입니다. 한 번 만들고 끝나는 게 아니라, 현장에서 반복된 변수가 상수를 갱신하러 되돌아옵니다.

1장의 예외 3단 처리, 2장의 Q3 환류, 3장 데이터 축의 마지막 칸. 전부 이 화살표 위에 있었습니다.

## 3. 핵심 개념 — 상수 · 준상수 · 변수

1장에서는 상수와 변수, 두 층으로만 이야기했습니다. 이제 층을 하나 더 넣습니다.

이유가 있습니다. 두 층만 있으면 **평수, 인원수, 상권 같은 것들을 넣을 자리가 없기 때문**입니다. 이것들은 매일 바뀌지 않으니 변수가 아니고, 그렇다고 영원히 고정도 아니니 상수도 아닙니다.

### 세 층의 실무 정의

| | **상수** | **준상수** | **변수** |
| --- | --- | --- | --- |
| **한 줄 정의** | 바뀌지 않을 기준 | 쉽게 안 바뀌는 조건값 | 매일 흔들리는 상황값 |
| **예시** | 역할 경계 · 승인 절차 | 평수 · 상권 등급 | 예약량 · 노쇼 · 날씨 |
| | 고객 응대의 원칙 | 인원 규모 · 구성 | 직원 컨디션 · 병가 |
| | 예외의 기록 의무 | 원장 배경 · 연차 | 클레임 발생 · 설비 고장 |
| | 브랜드가 지키는 선 | 비즈니스 유형(고객수/객단가) | 경쟁점 이벤트 |
| **다루는 법** | 개정은 가능하되, **절차를 거쳐 드물게** | 최초 1회 진단 + **분기·반기 재측정** | 실시간 대응 + **기록으로 데이터화** |

### 미용으로 옮기면

이 세 층은 원장님들이 이미 매일 쓰고 계신 구분입니다.

| 층 | 미용에서 | 살롱 운영에서 |
| --- | --- | --- |
| **상수** | **시술 프로토콜** — 패치테스트는 한다, 두피 상처 있으면 시술 안 한다 | 역할 경계 · 예외 기록 의무 |
| **준상수** | **모발 상태 · 두피 타입** — 6개월 지나면 다시 봐야 한다 | 평수 · 인원 · 상권 |
| **변수** | **오늘의 습도 · 고객 컨디션** — 그날 맞춰 조정하고 차트에 적는다 | 노쇼 · 병가 · 설비 고장 |

패치테스트를 오늘 습도에 따라 생략하지 않듯, 상수를 변수처럼 다루면 안 됩니다. 반대로 6개월 전 모발 상태를 오늘도 그대로 믿지 않듯, 준상수는 재측정해야 합니다.

**세 층의 구분은 새로운 개념이 아닙니다. 시술에서 하던 걸 매장에 하는 것입니다.**

## 4. 판별 도구 — 이것은 어느 층인가

무언가를 들고 왔을 때 어느 층에 넣을지 판단하는 세 질문입니다.

### 판별 질문 3

> **Q1. 변화 주기** — 이것이 바뀌려면 얼마나 걸리는가?
> 몇 년 이상 · 의도적 결정 = **상수** | 분기~연 단위 = **준상수** | 일~주 단위 = **변수**
>
> **Q2. 결정 주체** — 누가 바꿀 수 있는가?
> 원장의 공식 개정 = **상수** | 환경 · 시장이 바꿈 = **준상수** | 아무도 통제 못함 = **변수**
>
> **Q3. 대응 방식** — 이것에 어떻게 반응해야 하는가?
> 지킨다 = **상수** | 측정하고 설계에 반영한다 = **준상수** | 대응하고 기록한다 = **변수**

### 세 답이 갈리면?

> **→ 더 높은 층으로 임시 배정한 뒤, 분기에 재검토합니다. 안전한 쪽은 위쪽입니다.**

왜 위쪽이 안전한지 설명하겠습니다.

**상수로 잘못 올린 것**은 나중에 내리면 됩니다. 그동안 좀 불편했을 뿐입니다.
**변수로 잘못 내린 것**은 사고가 나야 발견됩니다. 그리고 그때는 이미 늦습니다.

애매하면 위로. 이건 미용도 같습니다. 손상 정도가 애매하면 강한 약이 아니라 약한 약부터 갑니다.

### Q3이 가장 실용적입니다

세 질문 중 현장에서 제일 빨리 답이 나오는 건 Q3입니다.

**"이걸 어떻게 해야 하지?"**

- 지켜야 할 것 같다 → 상수
- 재서 반영해야 할 것 같다 → 준상수
- 오늘 대응하고 적어 두면 될 것 같다 → 변수

Q1·Q2는 검산용으로 쓰십시오.

## 5. 왜 '굵은 상수'인가 — 경우의 수는 폭발한다

이 장의 제목이 왜 "경우의 수가 많을수록 상수를 굵게"인지, 이제 계산으로 보여 드리겠습니다.

### 살롱 조합의 수

| 축 | 구분 | 가짓수 |
| --- | --- | --- |
| 평수 | 소형 · 중형 · 대형 | ×3 |
| 상권 등급 | A급 · B급 · C급 | ×3 |
| 인원 규모 | 8명 · 15명 · 30명대 | ×3 |
| 구성 조합 | 디자이너 · 인턴 · 데스크 비율 | ×3 |
| 원장 배경 | 미용인 · 비미용인 | ×2 |

**= 162가지 조합.** 여기에 비즈니스 유형과 세대 구성까지 곱하면 **수백 가지**가 됩니다.

### 그래서 전략이 뒤집힙니다

| 전략 | 방식 | 결과 |
| --- | --- | --- |
| **규정 전략** | 조합마다 규정을 만든다 | 수백 개 규정 → **관리 불능** ❌ |
| **상수 전략** | 어떤 조합에서도 변하지 않는 기준을 **소수 정예로 굵게** 세운다 | 나머지는 준상수 블록의 조립으로 대응 ✅ |

> ### **굵은 상수 10여 개 × 좌표별 블록 = 수백 가지 조합 커버**
> ### **경우의 수가 많을수록, 상수는 더 적고 더 굵어야 합니다.**

### 미용으로 옮기면 — 레시피북 500개 vs 배합 원리 10개

신입 디자이너를 가르친다고 해 봅시다.

**방법 A.** 시술 케이스 500개를 정리한 레시피북을 줍니다. "8레벨 건강모에 애쉬 넣을 때는 이렇게, 8레벨 손상모는 이렇게, 7레벨 기염색모는…"

**방법 B.** 배합 원리 10개를 가르칩니다. 레벨과 언더톤의 관계, 손상도에 따른 볼륨 조절, 기존 색소의 처리 원칙.

어느 쪽이 500개 케이스를 커버합니까?

**B입니다.** 그리고 A는 501번째 케이스에서 무너집니다.

살롱 운영도 정확히 같습니다. 원장님들이 이미 아는 이 원리를, 매장에는 적용하지 않고 계셨을 뿐입니다.

## 6. 오분류 주의보 — 자주 틀리는 네 패턴

3층 문법을 배운 다음 실제로 틀리는 지점은 정해져 있습니다. 네 가지입니다.

### 패턴 1 — 변수를 상수로

> **"요즘 우리 매장에 20대 고객이 많다"**를 영구 기준처럼 굳힙니다.

그래서 인테리어도, 메뉴도, SNS도 전부 20대에 맞춥니다. 그런데 2년 뒤 근처에 대학가 상권이 이동하거나 아파트가 들어서면요? 상권이 바뀌었는데 전략이 못 따라갑니다.

**바른 분류:** 고객 구성은 **준상수** — 분기 재측정 대상입니다.

### 패턴 2 — 상수를 변수로

> **예외 기록 의무**를 "바쁘면 생략 가능"으로 취급합니다.

한 번 봐주면 두 번 봐주게 되고, 두 번이면 원칙이 아니라 권고가 됩니다. 그리고 원칙이 협상 대상이 되는 순간 1장의 병목 2로 돌아갑니다.

**바른 분류:** 기록 의무는 **상수** — **바쁨은 면제 사유가 아닙니다.**

가장 바쁜 날의 예외가 가장 중요한 예외입니다. 바쁘니까 판단이 급했을 거고, 급한 판단일수록 기록이 필요합니다.

### 패턴 3 — 준상수를 상수로

> **"우리는 8인 매장 방식으로 한다"**를 15인이 되어도 고수합니다.

이게 성장기 살롱에서 제일 흔합니다. 그리고 제일 안 보입니다. 방식이 잘못된 게 아니라 **방식의 유효기간이 끝난 것**이니까요. 1장에서 했던 이야기입니다.

**바른 분류:** 규모는 **준상수** — 좌표가 바뀌면 블록을 교체합니다.

### 패턴 4 — 상수를 준상수로

> **역할 경계**를 "관리자 바뀔 때마다 재협상"합니다.

새 관리자가 오면 "어디까지 하실 수 있어요?"부터 묻습니다. 배려처럼 보이지만, 이러면 사람마다 다른 경계가 생깁니다. **2장이 통째로 무너집니다.**

**바른 분류:** 경계는 **상수** — 사람이 아니라 자리에 부여합니다.

### 네 패턴을 한 줄로

| 오분류 | 결과 |
| --- | --- |
| 변수 → 상수 | 못 바꾼다 (경직) |
| 상수 → 변수 | 안 지킨다 (붕괴) |
| 준상수 → 상수 | 성장을 못 따라간다 (정체) |
| 상수 → 준상수 | 사람마다 달라진다 (분열) |

## 7. STEP 1 · 상수 — 분류 문법 4원칙

### 상수 1 — 새 문제 앞에서 규정 신설은 마지막 수단이다. 먼저 기존 상수로 답을 찾는다.

문제가 생겼을 때 손이 먼저 가는 곳이 공지 작성입니다. 그 손을 한 번만 멈추십시오.

**"이거 우리 상수로 답이 나오나?"**

열에 여섯은 나옵니다. 나오면 새 규정이 아니라 **기존 상수를 다시 알리는 것**으로 처리합니다. 이 둘은 완전히 다릅니다. 하나는 규정집을 늘리고, 하나는 상수를 굵게 만듭니다.

### 상수 2 — 상수는 소수 정예로 유지한다. 10여 개를 넘으면 상수가 아니라 규정집이다.

**10여 개.** 이 숫자를 기억하십시오.

상수가 20개가 되면 아무도 못 외웁니다. 못 외우는 상수는 상수가 아닙니다. 1장의 상수 2를 떠올려 보십시오. *꺼내 볼 수 있으면 문서입니다.* 여기에 하나를 덧붙이겠습니다. **외울 수 있어야 상수입니다.**

### 상수 3 — 준상수는 측정 주기를 갖는다. 최초 1회 진단 후 분기·반기 재측정을 달력에 박는다.

"나중에 다시 봐야지"는 안 봅니다.

**달력에 박으십시오.** 분기 첫째 주 월요일, 준상수 재측정. 담당자 지정. 이게 없으면 준상수는 조용히 상수가 되어 버립니다(오분류 패턴 3).

### 상수 4 — 변수는 반드시 기록된다. 기록 없는 변수 대응은 경험이 아니라 증발이다.

오늘 노쇼가 3건 났고, 대응을 잘했습니다. 기록 안 하면 그건 그냥 힘든 하루였습니다.

기록하면 데이터가 됩니다. 그리고 석 달 뒤 "화요일 오전 노쇼가 유독 많다"는 패턴이 보입니다. 그러면 그건 **더 이상 변수가 아닙니다.** 상수 개정 후보가 됩니다.

## 8. STEP 2 · 변수 — 우리 매장의 분류 현주소

| 축 | 진단 질문 | 판정 |
| --- | --- | --- |
| **상수 개수** | '우리 매장의 상수'를 지금 몇 개나 쓸 수 있는가? | 0개 = **문법 부재** |
| **규정 총량** | 규칙 · 공지 · 지침의 총 개수를 아는 사람이 있는가? | 모름 = **인플레** |
| **신설 속도** | 최근 3개월 신설 규정이 폐지 규정보다 많은가? | 많음 = **남발 중** |
| **재측정 달력** | 준상수의 재측정 일정이 달력에 존재하는가? | 없음 = **방치** |
| **변수 기록** | 돌발 상황의 대응이 기록으로 남는가? | 안 남음 = **증발** |
| **환류 실적** | 반복 변수가 상수 개정으로 이어진 사례가 있는가? | 없음 = **학습 정지** |

### 마지막 질문이 가장 중요합니다

**환류 실적.** 반복되는 변수가 상수를 바꾼 적이 있습니까?

없다면 우리 매장은 **경험은 쌓이는데 학습은 안 되는 상태**입니다. 3년을 해도 3년어치 경험이 아니라 1년어치 경험을 세 번 한 것이 됩니다.

이 진단이 0이면, 앞의 다섯 개를 아무리 잘 해도 매장은 제자리입니다.

## 9. STEP 3 · 결정 규칙 — 새 문제가 발생했다

### 처리 플로우 4단계

> **Q1. 기존 상수로 답이 나오는가?**
> └ **YES** → 상수를 적용하고 알린다. **규정 신설 금지**
>
> **Q2. 좌표(준상수)가 달라져 생긴 문제인가?**
> └ **YES** → 준상수를 재측정하고 **운영 블록을 교체**한다
>
> **Q3. 일회성 돌발 상황인가?**
> └ **YES** → 변수로 대응하고 **기록**한다. **규정화하지 않는다**
>
> **RULE.** 같은 변수가 **3회 이상 반복되면 상수 개정 후보로 상정**한다 — 환류의 발동 조건

### Q2가 이 플로우에서 가장 자주 누락됩니다

Q1(상수로 해결)과 Q3(변수로 대응)은 직관적입니다. 그런데 **Q2를 아무도 안 봅니다.**

Q2는 이렇게 묻습니다. **"이 문제, 사실은 우리가 커져서 생긴 거 아닌가?"**

예를 들어 최근 들어 예약 착오가 잦아졌습니다. Q1으로 가면 "예약 확인 절차 재공지"가 나옵니다. Q3으로 가면 "그날 바빴네"가 됩니다.

그런데 Q2로 보면 다릅니다. **작년엔 8명이었고 지금은 14명입니다.** 8명일 때 쓰던 예약 관리 방식이 14명에서 안 돌아가는 겁니다. 이건 재공지로 해결되지 않습니다. **블록을 교체해야 합니다.**

오분류 패턴 3(준상수를 상수로)이 이 지점에서 발생합니다. Q2를 건너뛰면 성장통을 규율 문제로 오진하게 됩니다.

### RULE — 3회의 의미

**같은 변수 3회.** 왜 3회인가.

1회는 우연입니다. 2회는 우연일 수도 있습니다. **3회부터는 패턴입니다.**

그리고 이 숫자가 중요한 이유는, 숫자가 없으면 환류가 안 일어나기 때문입니다. "자주 생기면 규칙으로 만들자"는 영원히 실행되지 않습니다. '자주'가 몇 번인지 아무도 모르니까요.

변수 로그에 3회 알림을 걸어 두십시오. 3회째에 자동으로 상수 개정 논의가 시작되게. 이게 매장이 학습하는 유일한 방법입니다.

## 10. STEP 4 · 현장 사례 — 규정 74개 매장이 상수 12개로 다이어트한 과정

### 상황

문제가 생길 때마다 공지를 붙여 온 60평 매장이었습니다. 3년 누적 **규정·공지 74건.**

74건이 되기까지 아무도 못 알아챈 이유가 있습니다. **한 번에 74개를 만든 게 아니라 한 달에 두 개씩 만들었기 때문**입니다. 매번은 합리적이었고, 총합은 재앙이었습니다.

증상은 이렇게 나타났습니다.

- 서로 **모순되는 조항**이 발견됩니다
- 신입 교육 자료는 **아무도 최신본을 모릅니다**
- 팀원들은 **'상황에 따라 유리한 공지'를 인용**하기 시작합니다
- 원장은 "규정이 있는데 왜 안 지키냐"며 갈등이 심해집니다

원장님의 그 말씀에 팀원들은 대답을 못 했습니다. 대답이 이랬거든요. **"지킬 수가 없었습니다. 74개니까요."**

### 매트릭스 재해석 — 전수 분류

74건을 전부 꺼내 3문 판별에 통과시켰습니다.

| 분류 | 건수 |
| --- | --- |
| **상수** | 12 |
| **준상수** | 9 |
| **변수 대응 메모** | 31 |
| **중복 · 폐기** | 22 |
| **합계** | **74** |

숫자를 보십시오. **74건 중 53건(변수 메모 31 + 폐기 22)이 애초에 규정이 아니었습니다.**

- **31건**은 그날의 대응 기록이었습니다. 규정이 아니라 **변수의 흔적**이었죠.
- **22건**은 이미 있는 것을 다시 말한 것이거나 폐기 대상이었습니다. **상수의 반복 설명**이었습니다.

### 재편 결과

74건짜리 규정집이 세 개의 문서로 재구성됐습니다.

1. **1페이지 상수 헌장** (12개)
2. **좌표표** (준상수 9개 + 재측정 주기)
3. **변수 로그** (진행형 기록처)

그리고 **신입 교육이 1주 안에 가능**해졌습니다. 74건일 때는 불가능했던 일입니다.

### 교훈

> **규정의 대부분은 상수의 반복 설명이거나 변수의 흔적이었습니다.**
> **문법이 생기자 문서가 줄었습니다.**

이 매장은 규칙을 새로 만들지 않았습니다. **분류만 했습니다.** 그런데 74개가 12개가 됐습니다.

미용으로 옮기면 이렇습니다. 약장에 약이 74개 있었는데, 정리해 보니 같은 약이 이름만 다르게 세 병씩 있었고, 절반은 유통기한이 지났고, 진짜 쓰는 건 12개였던 것.

**약을 더 산 게 아니라 약장을 정리한 것입니다.**

## 11. STEP 5 · 실행 도구 — 3층 분류표

우리 매장 규칙 전수 분류 시트입니다. 여섯 단계로 진행합니다.

| 단계 | 내용 | 요령 |
| --- | --- | --- |
| **① 전수 나열** | 규정 · 공지 · **암묵 규칙**을 빠짐없이 한 열에 나열 | **문서 안 된 관행 포함**이 핵심 |
| **② 3문 판별** | 각 항목에 판별 질문 3(변화 주기 · 결정 주체 · 대응 방식) 적용 | 애매하면 위층으로 |
| **③ 4분류 배정** | 상수 / 준상수 / 변수 흔적 / 중복·폐기 중 하나로 배정 | 폐기를 두려워하지 마십시오 |
| **④ 상수 압축** | 상수 후보를 **10여 개로** 압축하고 한 문장씩 다듬기 | '~한다'로 끝나는 선언문으로 |
| **⑤ 재측정 달력** | 준상수마다 재측정 주기(분기/반기)와 **담당** 지정 | 담당자 이름을 반드시 |
| **⑥ 변수 로그 개설** | 변수 대응을 기록할 **한 곳**을 정하고 **3회 반복 알림** 설정 | 노션 · 시트 · 노트, 뭐든 한 곳 |

### ①번의 '암묵 규칙'을 빠뜨리지 마십시오

가장 많이 생략되고, 가장 중요한 항목입니다.

문서로 안 되어 있는데 다들 지키는 것들. "원장님 계실 땐 음악 볼륨 낮춘다" "금요일엔 마감 청소를 두 배로 한다" "그 고객은 A 실장만 응대한다."

이런 게 실제로는 규정보다 강하게 작동합니다. **그리고 신입만 모릅니다.** 그래서 신입이 눈치를 배우는 겁니다.

암묵 규칙을 꺼내 놓는 것만으로도 매장이 절반은 정리됩니다.

### ④번 — 상수 문장 다듬는 법

2장과 1장에서 이미 연습하셨습니다. 다시 정리하면,

- **'~한다'로 끝나는 선언문**으로
- **누가 · 언제 · 무엇을**이 들어가게
- **판정 가능하게** (지켰는지 안 지켰는지 누가 봐도 알 수 있게)

나쁜 예: "고객 응대에 최선을 다한다"
좋은 예: "신규 고객 방문 시 담당 디자이너가 시술 전 카운셀링 시트를 작성한다"

*이 시트는 부록 A(진단 인테이크)의 사전 작업이며, 8장에서 운영 코드 도출의 원재료가 됩니다.*

## 12. 워크숍 — 미니 규정 다이어트

### 조별 수업 버전 (15분)

| 단계 | 내용 | 시간 |
| --- | --- | --- |
| **1. 수집** | 오프닝에서 적은 최근 3개월 신설 규칙 + 기억나는 기존 규칙 = **10개** | 3분 |
| **2. 판별** | 10개를 3문 판별에 통과시켜 4분류로 배정 | 6분 |
| **3. 압축** | 상수로 분류된 것을 한 문장씩 다듬기 — '~한다'로 끝나는 선언문 | 4분 |
| **4. 공유** | **조별 폐기율**(폐기 + 변수 흔적 ÷ 10) 발표 — 폐기율이 곧 규정 인플레 지수 | 2분 |

### 혼자 읽는 독자를 위한 버전

10개만 하십시오. 그리고 **폐기율을 계산하십시오.**

| 폐기율 | 판정 |
| --- | --- |
| **30% 미만** | 규정 관리가 잘 되고 있습니다. 전수 분류는 여유 있게 하셔도 됩니다. |
| **30~60%** | 일반적인 성장기 살롱입니다. 전수 분류를 권합니다. |
| **60% 이상** | 규정 인플레 상태입니다. **전수 분류가 시급합니다.** 사례의 60평 매장은 72%였습니다. |

폐기율이 높다고 원장님이 일을 잘못하신 게 아닙니다. **문법 없이 성실했던 결과**입니다. 성실하지 않았으면 74건이 안 나왔을 테니까요.

## 장을 닫으며 — 4장 핵심 세 줄

> **1. 경우의 수가 많을수록 상수는 더 적고 더 굵어야 합니다.**
> 규정은 조합을 못 쫓아갑니다. 162가지 조합에 162개 규정으로 대응할 수는 없습니다.
>
> **2. 분류가 곧 관리입니다.**
> 상수는 지키고, 준상수는 재고, 변수는 기록합니다. 세 가지를 섞으면 셋 다 안 됩니다.
>
> **3. 같은 변수 3회 반복이면 상수 개정 후보입니다.**
> 기록이 있어야 매장이 학습합니다.

**구조 좌표** — 평수 · 상권 등급 · 지점 수라는 물리적 조건이 운영 방식을 어떻게 결정하는지 다룹니다. 그리고 규모 × 상권 매트릭스에 우리 매장을 직접 찍어 봅니다.

5장에서 이런 문장을 만나게 되실 겁니다. **"전략에 절대적 정답은 없다. 좌표에 대한 정답만 있다."**

## 과제 — 다음 장으로 넘어가기 전에

1. **3층 분류표 ①~③을 매장 전체 규칙으로 확장 수행하십시오.**
   암묵 규칙 포함, **최소 20개.** 20개가 안 나오면 아직 다 안 꺼내신 겁니다.

2. **상수 후보를 10개 이내로 압축해 '상수 헌장 초안'을 1페이지로 만드십시오.**
   1장·2장·3장에서 세운 상수들이 이미 12개입니다. 그중 우리 매장에 맞는 것부터 채우시면 됩니다.

3. **변수 로그를 실제로 개설하고, 일주일간 발생한 변수와 대응을 기록해 오십시오.**
   노션이든 구글 시트든 카운터 노트든 상관없습니다. **한 곳이면 됩니다.** 두 곳이면 그건 없는 것과 같습니다.

*과제 3의 변수 로그는 5~8장 내내 사용되며, 22장(변수 대응)에서 최종 분석 재료가 됩니다.*
