# 관리자론 — 헤어살롱 편

> **미용 시장 관리자 운용 바이블 · 전 3권**
> 「운영 관리자 · 매트릭스 대입 수업」 강의안을 3부작 단행본 원고로 옮기는 작업 저장소

---

## 이 시리즈는

중대형 살롱(40평 이상 · 8인 이상)과 다점포(2개 지점 이상) 원장, 그리고 총괄 관리자를 지향하는 관리자를 위한 운영 실무서입니다.

핵심 프레임은 **운영 관리자 매트릭스 = 상수 × 준상수 × 변수** 입니다.
상수는 지키고, 준상수는 재고, 변수는 기록합니다. 남의 매장 답을 베끼는 대신 **우리 매장의 좌표에서 답을 도출**하도록 설계했습니다.

시리즈를 관통하는 질문은 하나입니다.

> **좋은 관리자가 일할 수 있는 매장은 어떻게 만들어지는가?**

| 권 | 제목 | 핵심 질문 | 권말 산출물 | 분량 |
| --- | --- | --- | --- | --- |
| **1권** | 기준과 진단 | 우리 매장에는 어떤 관리자가 필요한가? | 관리자 모델 결정서 | 20개 절 · 185쪽 |
| **2권** | 권한과 운영 | 그 관리자는 무엇을 결정하고 무엇을 돌려야 하는가? | 운영 문서 세트 | 16개 절 · 141쪽 |
| **3권** | 확장과 양성 | 그 사람이 없어도, 장소가 달라져도 유지되는가? | 90일 로드맵 · 양성 계획 | 15개 절 · 139쪽 |

각 권은 독립적으로 읽을 수 있습니다. 2권과 3권에는 앞 권을 읽지 않은 독자를 위한 **입구**(최소 개념과 빈 양식)가 있습니다.

## 저장소 구조

```
원고/
  1권/  총서문 · 프롤로그 · 용어 · 1~12장 · 막간 · 권말실습 · 에필로그 · 2권예고 · 부록   ✅
  2권/  입구 · 프롤로그 · 1~10장 · 권말실습 · 에필로그 · 3권예고 · 부록                  ✅
  3권/  리캡 · 입구 · 프롤로그 · 1~8장 · 권말실습 · 에필로그 · 마무리 · 부록              ✅
docs/
  책-구성안.md      3부작 기획 · 권별 구성 · 편집 규약 · 저자 확인 항목
  집필-가이드.md    변환 규칙 · 문체 · 위트 규정 · 은유 체계
  재구성-대조표.md   편집자 인수인계 — 원문 30장 → 3권 대조, 찾아 바꾸기 규칙 (원본)
  재구성-대조표.html 같은 내용의 웹 판 — 장 검색 필터 포함
source/
  NN장-강의안-원문추출.txt   원문 30장 강의안 — 집필 근거
tools/
  build_all.sh        전체 산출물 일괄 빌드
  build_reader.py     원고 → 워크북 리더 (세 권 통합 HTML)
  build_manuscript.py 원고 → 권별 단행본 원고 마크다운
  md_to_json.py       마크다운 → 조판용 블록 JSON
  make_docx.js        블록 JSON → Word 원고 (docx-js)
  fix_opc.py          docx OPC 파트 순서 교정
  build_print.py      원고 → 인쇄용 HTML
  pdf.js              인쇄용 HTML → 권별 PDF (Chromium)
  make_bundle.py      배포용 묶음 생성
build/
  1권/ 2권/ 3권/      각 권의 .md · .docx · .pdf
  편집자/             재구성 대조표 .md · .docx · .pdf · .html
  reader.html         워크북 리더 — 아티팩트로 발행
  관리자론-3부작.zip   배포용 묶음 (git 미추적)
```

**전체 빌드:** `bash tools/build_all.sh`
**리더만:** `python3 tools/build_reader.py build/reader.html`

원고의 `☐`는 실제 체크박스로, `____`는 입력칸으로 변환되어 읽기 자료가 곧 워크북이 됩니다(입력 1,381개).

### 빌드 주의사항

- **docx OPC 순서** — docx-js는 `[Content_Types].xml`을 패키지 첫 항목으로 두지 않습니다.
  Word는 허용하지만 LibreOffice 등은 파일을 열지 못하므로 `fix_opc.py`로 재패킹해야 합니다.
- **PDF 폰트** — Gowun Batang · IBM Plex Sans KR을 시스템에 설치한 뒤 렌더링합니다.
  없으면 한글이 중국어 폰트로 대체됩니다.

## 진행 현황

**3부작 재구성 완료 · 부록 14종 제작 완료.** 51개 절 · 상수 120개 · 본문 약 47만 자 · 조판 합계 465쪽.

원문 30장 체제에서 3권 체제로 옮기면서 처리한 것:

| 작업 | 규모 |
| --- | --- |
| 장 번호 상호 참조 재매핑 | 1,286건 |
| 원문 8개 부 → 권 안의 섹션 | 207건 |
| 강의 회차·종강 전제 제거 | 24건 |
| 조별 수업 → 공동 실습 | 39건 |
| 권두·권말 신규 집필 | 16개 절 |
| 부록 실물 양식 제작 | 14종 (1권 4 · 2권 6 · 3권 4) |
| 부록 참조 권별 재번호 | 31건 |

기존 30장 구성으로 작업하시던 편집자를 위한 대조표는 [`docs/재구성-대조표.md`](docs/재구성-대조표.md)에 있습니다.
`build/편집자/`에 PDF · Word · 웹 판이 함께 생성됩니다.
장 번호 매핑, 바뀐 줄의 성격, 찾아 바꾸기 규칙, 신규 집필 목록이 정리되어 있습니다.

**다음 단계:** 전권 교정.
저자 확인이 필요한 항목 10건은 [`docs/책-구성안.md`](docs/책-구성안.md) 5절에 정리되어 있습니다.

## 작업 방식

1. 장별 강의안 PDF를 전달합니다.
2. [`docs/집필-가이드.md`](docs/집필-가이드.md)의 변환 규칙에 따라 원고를 집필합니다.
   - 슬라이드의 **상수·변수·판정 수치는 변경하지 않습니다.**
   - 단문 불릿은 **"왜 그런가 + 현장에서 어떻게 나타나는가"**로 확장합니다.
   - 강의를 듣지 않은 독자도 혼자 완결할 수 있도록 보충합니다.
3. 원고를 커밋하고 구성안의 진행 현황을 갱신합니다.
