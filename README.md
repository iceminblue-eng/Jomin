# 관리자론 — 헤어살롱 편

> **미용 시장 관리자 운용 바이블**
> 「운영 관리자 · 매트릭스 대입 수업」 강의안을 단행본 원고로 옮기는 작업 저장소

---

## 이 책은

중대형 살롱(40평 이상 · 8인 이상)과 다점포(2개 지점 이상) 원장, 그리고 총괄 관리자를 지향하는 관리자를 위한 운영 실무서입니다.

핵심 프레임은 **운영 관리자 매트릭스 = 상수 × 변수** 입니다.
상수는 복사하고, 변수는 진단합니다. 남의 매장 답을 베끼는 대신 **우리 매장의 좌표에서 답을 도출**하도록 설계했습니다.

---

## 저장소 구조

```
원고/
  제1부/  01장 · 02장 · 03장                    ✅ 1부 완결
  제2부/  04장 · 05장 · 06장 · 07장 · 08장      ✅ 2부 완결
  제3부/  09장 · 10장 · 11장                    (12장 대기)
docs/
  책-구성안.md      전체 목차 · 장 간 연결 · 상수 목록 · 진행 현황
  집필-가이드.md    변환 규칙 · 문체 · 위트 규정 · 은유 체계
source/
  NN장-강의안-원문추출.txt   원본 PPT 텍스트 — 집필 근거
tools/
  build_reader.py   원고 마크다운 → 읽기용 HTML 빌드
  reader.css / reader.js
build/
  reader.html       아티팩트로 발행되는 결과물
```

**빌드:** `python3 tools/build_reader.py build/reader.html`
원고의 `☐`는 실제 체크박스로, `____`는 입력칸으로 변환되어 읽기 자료가 곧 워크북이 됩니다.

| 부 | 장 | 제목 | 상태 |
| --- | --- | --- | --- |

| 제2부 | 8장 | 진단 인테이크로 살롱의 운영 코드를 만든다 | ✅ |
| 제3부 | 9장 | 선수형 관리자 | ✅ |
| 제3부 | 10장 | 오피스형 관리자 | ✅ |

전체 규모는 **최소 29장 + 부록 A~J**입니다. 자세한 내용은 [`docs/책-구성안.md`](docs/책-구성안.md) 참고.

## 작업 방식

1. 장별 강의안 PDF를 전달합니다.
2. [`docs/집필-가이드.md`](docs/집필-가이드.md)의 변환 규칙에 따라 원고를 집필합니다.
   - 슬라이드의 **상수·변수·판정 수치는 변경하지 않습니다.**
   - 단문 불릿은 **"왜 그런가 + 현장에서 어떻게 나타나는가"**로 확장합니다.
   - 강의를 듣지 않은 독자도 혼자 완결할 수 있도록 보충합니다.
3. 원고를 커밋하고 구성안의 진행 현황을 갱신합니다.
